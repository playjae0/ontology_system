# 문서 개요 지시문 (LLM 지점 ⑪문서 개요 · 제목 계층만 본다)

> **이 파일이 정본이다**(문서 7 §7.6-B-5) — 위 `version:`이 개요 체크포인트에 기록되고, 바뀌면 개요를 다시 묻는다.
> **층 어휘를 여기에 적지 않는다**(문서 1 B9) — 카테고리 이름 · 정의문은 층 config가 소유하고 실행 시 조립된다.
> 입력은 **제목 계층뿐이다** — 청크 본문은 오지 않는다(다른 청크의 본문을 넣지 않는다 · 사용자 2026-10-15).

## 지시문

문서의 제목 계층(시트 이름 · 장 · 절 · 슬라이드 제목)을 보고, **제목마다** 그 제목이 **대상**(아래 닫힌 카테고리의
하나 — 그 제목 아래의 글이 「그것의 일부 · 특성」을 말하는 구체적인 것)인지, 아니면 **주제 이름일 뿐**(개요 · 사양 ·
일정 · 검토 결과처럼 무엇에 대한 글인지를 말하는 이름)인지를 고른다.

1. **대상이면 이름과 카테고리를 낸다** — 이름은 **제목에 적힌 글자 그대로**의 일부다(번호 · 기호를 뗀 것:
   「3. 추출부」 → 「추출부」 · 「2) NG unit」 → 「NG unit」). **제목에 없는 이름을 지어내지 않는다** — 하류가 제목
   글자와 대조해 밖이면 버린다.
2. **카테고리는 `{{categories}}`의 닫힌 목록에서만** 고른다 — 정의문에 맞지 않으면 대상이 아니다(`target: null`).
3. **애매하면 주제로 둔다**(`target: null`) — 하류는 주제 제목을 건너뛰고 그 위 제목으로 올라간다. 틀린 대상이
   빠진 대상보다 비싸다(제목 아래 개체가 엉뚱한 것에 붙는다).
4. **부모는 바꾸지 않는다** — 제목의 위아래는 `parent`가 이미 정했다. 너는 제목 하나하나의 대상 여부만 낸다.
5. 모든 제목 id에 하나씩 답한다(목록 밖 id는 버려진다).

### 조립되는 것 (호출부가 채운다)

| 자리 | 무엇 | 출처 |
|---|---|---|
| `{{categories}}` | 닫힌 카테고리 목록 + 정의문(겸이 있으면 정의문 끝에 한 줄) | 층 config `categories` + 공통 config `also` |
| `{{headings}}` | 제목 `[{id, text, parent, depth}]` — `parent`는 위 제목의 id(맨 위는 null) | 청크의 시트 이름 · `meta.section_path` |

### 출력 형식

```json
{"headings": [{"id": 1, "target": {"name": "…", "category": "…"} | null}]}
```
