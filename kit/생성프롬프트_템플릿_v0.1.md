# 어댑터·매칭 스키마 생성 프롬프트 템플릿 v0.1

> 킷 구성물 1(파서_명세 §9). 등록 세션에서 LLM에 제시하는 지시문의 초안.
> 관찰 범위 규칙(M5)과 힌트 삽입 위치는 이 템플릿에 **고정**되며 세션마다 바뀌지 않는다(⑵-②).

---

## [지시]

당신은 신규 문서 양식 하나를 등록하는 작업을 맡았다. 표본 문서를 관찰해 **매칭 스키마 초안**(필드별 role 배정 + 필드 사이 엣지 선언)을 산출하라.

**관찰 범위 규칙 (고정)**
- 정형(표 형태): 헤더와 데이터 **약 10줄**이면 형식·내용이 드러난다.
- 비정형(줄글·목차형): 10~30줄. 목차형처럼 같은 패턴이 반복되면 **계층 패턴이 2~3회 반복해 나타날 때까지** 확장한다.

**관찰 체크리스트**: 들여쓰기 · 열 위치 · 번호 패턴 · 서식(굵게 등) · 병합 셀 · 빈 셀 · 상동 기호.

## [role 어휘 — 이 6가지 중 하나를 필드마다 고른다]

role은 **그 필드의 값으로 그래프에 수행하는 쓰기 동작**이다. 필드의 이름이나 중요도가 아니라 "이 값으로 그래프에 무엇을 하는가"로 판단한다.

| role | 뜻 | 판별 |
|---|---|---|
| `anchor` | 이미 존재하는 **골격 노드를 찾아라**(해소). 새로 만들지 않는다 | 값이 아래 골격 닫힌 목록 안에 있는가 |
| `entity` | **노드가 될 자격이 있는 것**을 데려와라. 이름을 갖고 다른 것과 구별된다 | "이것에 대해 더 말할 게 생기는가?" → 예 |
| `attribute` | 어떤 것 **자체가 아니라 어떤 것에 붙어 있는** 성질·값. 노드를 만들지 않고 노드의 필드에 저장 | "이것에 대해 더 말할 게 생기는가?" → 아니오. 구조체·배열도 통째로 하나의 값 |
| `content` | 구조화되지 않은 **자유 서술 텍스트**. 필드 단위 규칙 처리가 불가능한 산문 | 청크로 보존해 관련 노드에 연결한다 |
| `meta` | 내용물이 아니라 **내용물의 신상정보**. 그래프에 넣지 않고 출처 장부에만 적는다 | 개정번호·작성일 같은 관리 정보 |
| `UNMAPPABLE` | **위 5종 어디에도 맞지 않는다.** 추측하지 말고 이것을 고르고 이유를 적는다 | 사람이 판정한다 |

**중요**: role 5종은 그래프가 허용하는 쓰기 동작을 전수 열거한 것이다. 억지로 끼워 맞추지 말고, 맞지 않으면 `UNMAPPABLE`을 골라라. 판단이 서지 않는 필드는 `UNMAPPABLE` + "판정 불가" 사유로 올린다 — 그것이 검수 화면에서 사람에게 질문으로 표시된다.

### role별 선택 속성

- `entity`: `category`(필수, 아래 층 카테고리에서), `attach_to_field`, `target_layer`(다른 층에 기록할 때만)
- `attribute`: `attach_to_field`, `attr_name`, `contextual`(맥락별로 값이 갈리면 true)
- `anchor`: `target_category`(공정 골격이 아닌 다른 골격을 볼 때만)
- `content`: `attach_to_field`
- 전체: `optional`(빈 값 허용)

### edges 선언

관계는 필드 하나의 성질이 아니라 필드 **사이**의 성질이므로 스키마 레벨에 선언한다.
형식: `{from, relation, to, optional?}` — `from`/`to`는 필드명 또는 `@좌표필드` 참조.

## [층 어휘 — process 층]

**카테고리 (닫힌 목록)**

- `Process` — 제품을 만들기 위해 수행하는 작업 단계. 기능으로 정의되며 설비 기종이 바뀌어도 존재한다(예: 노칭, 스태킹). 설비 이름이 아니라 '하는 일'의 이름.
- `Unit` — 공정을 수행하는 물리 장비의 기종/표준 명칭(예: 노칭 프레스). 지그·금형 등 도구류 포함. 호기·특정 공장 개체는 제외.
- `Property` — 공정/설비에서 관리·측정·통제되는 항목의 **이름**(예: 노칭 정밀도). 관리항목/특성/CTQ 포함. **규격값·측정값·판정결과는 제외**(그것은 attribute).

**관계 (닫힌 목록)**: `part_of`, `precedes`, `has_property`, `mirrors`
