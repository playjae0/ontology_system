# 이연 대장 — 미룬 것이 어디에 있나

> **왜 이 파일이 있나.** 이연 항목이 개정대장·BLOCKERS·감사 결과·대화에 흩어져 있어서, 세션이 바뀌거나 컨텍스트가 압축되면 **요약본에 기대게 된다.** 이 파일 하나만 읽으면 미룬 것이 전부 보이게 한다.
> **갱신 규칙**: 회차를 닫을 때 여기부터 본다. 닫힌 항목은 지우지 말고 「닫힘」 줄을 단다 — 왜 미뤘고 언제 풀렸는지가 판단 이력이다.
> **최종 갱신**: 2026-09-10 (B58 ⑤ 완료 · ⑥까지 하고 실측으로 — §AR)
