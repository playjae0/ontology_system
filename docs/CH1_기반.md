## 1.1 목적과 범위 [확정]

### 무엇인가

**사내 제조 문서를 넣으면 자동으로 지식 그래프까지 만들어지고, 자연어로 물으면 근거와 함께 답하며, 정보층을 계속 추가해도 코드가 늘지 않는 시스템.** (틀 §1의 한 문장 — 전 문서의 최상위 요약)

| 축 | 내용 | 챕터 |
|---|---|---|
| 축1 · 쓰기 | 문서 → 그래프 (정형/비정형 상이) | CH2(계약·등록) · CH3A/3B(인입) |
| 축2 · 층 | 새 정보층의 생성과 기존 층과의 연결 | CH4 |
| 축3 · 읽기 | RAG 질의 | CH5 |

### 규약

1. 사내에서 **지속 운영·확장 가능한** 온톨로지/GraphDB 시스템을 만든다. 공정정보층에서 시작해 층을 추가하고, 층간 연결로 지식을 확장한다.
2. 제조정보 특성상 **관계성이 1급 시민**이다. 주 문서는 Excel(밀도 높은 공정 spec·관리정보)과 PPT(글+이미지 복합), Word/PDF는 보조.
3. **데이터는 사내 반출 불가 → 파서는 사내 구현.** 외부에서 설계하는 것은 파서 출력(JSON)을 소비하는 온톨로지 에이전트와 플랫폼이다.
4. **모든 결합은 파일 계약(JSON)뿐이다.** 파서↔에이전트↔플랫폼은 코드가 아니라 JSON으로 만난다. 파서 내부 구현(어댑터 코드 생성 포함)은 에이전트 호환성과 무관하다 — 에이전트는 출력 계약(CH2)만 의존·검증한다.

### 원천

## 1.2 PoC 범위 [확정]

### 규약

1. **PoC = 공정층 구축 + 품질지식층 구축 + 층간 연결까지.** 근거: Rule of Three(CH4.2)상 2번째 층이 실재해야 공통 경계와 층간 연결의 실물 답이 관찰된다 — PoC는 데모이자 **설계 검증 실험**을 겸한다.
2. 2번째 층 = **품질지식층**(PFMEA류의 정적 지식 체계). 실제 발생 사건을 담는 불량이력층(사건 스트림·시점 보유)과 성격이 다르므로 구분 — 불량이력·자재/BOM은 3번째 층 후보(R5).
3. PoC 공정층은 **조립 대공정만** 심는다 — 전극/화성은 seed 키 추가로 확장.
4. 질의 지원 범위: **Q1~Q5·Q8**(CH5.3). Q6은 훅만, Q7은 범위 밖.
5. PoC 완료의 정의는 CH7.1(로드맵 국면 3)에 있다: plateau + 층간 연결 동작 + 골든셋 통과 + 계기판 가동.

### 원천
명세 §1.1. CH4.2, CH5.3, CH7.1.

## 1.3 불변 원칙 P1~P7 [확정]

### 무엇인가

전 시스템이 지키는 7원칙. 불변식 카드 A그룹의 원문이며, 다른 모든 규칙은 이 7개의 전개다.

| # | 원칙 |
|---|---|
| P1 | **단계 간 결합은 파일 계약(JSON)으로만.** 한 단계를 고쳐도 다른 단계 코드는 건드리지 않는다 |
| P2 | **골격·유형(Tier1)은 사람이 고정**, 인스턴스(Tier2)는 자동 생성 + 사후 수정 |
| P3 | **코어 코드는 최소·안정, 사람이 전부 파악.** 단방향 의존 |
| P4 | **id 불변, 동의어 사전이 영속 지식**, 임베딩은 비저장·재생성 가능한 도구. **노드 유일성 불변식**: 같은 개념(같은 canonical, 같은 정체성 축)은 언제나 한 노드 — 재인입·재빌드·동시 실행 등 어떤 경로에서도 중복 생성 금지. 중복 발생은 구현 편의가 아니라 **불변식 위반**으로 취급 |
| P5 | **진실 = 그래프(JSON: 노드·엣지) + 청크 원문(전 청크 보존).** Neo4j·Cypher·시각화·임베딩 인덱스는 재생성 가능한 파생물/뷰. 문서 근거 없는 엣지는 confirmed 불가 |
| P6 | **질의는 읽기 전용** — 질문 표현을 사전에 누적하지 않음(사용자 입력은 비검증, 사전 오염 방지) |
| P7 | **측정이 복잡도를 정당화한다** — 근거 없는 구조 선반영 금지 |

### 경계와 오해

- **틀 v2.2 이후에도 P1~P7은 문안 그대로 유지된다.** 두 모드·게이트·I축은 전부 이 원칙들의 전개이지 수정이 아니다 — 예: 커밋 게이트는 P2의 실행 장치, 근거 축 id는 P4의 근거 축 절반, 검수 1회는 P7(등록 산출물은 곱해지는 지렛대)의 적용.
- P4의 "id 불변"은 **의미 축**의 발급 id 이야기다. 근거 축은 내용 계산이므로 "불변"이 아니라 "결정적"이 정확한 술어다(CH6.1) — 같은 내용이면 언제나 같은 id.

### 원천
명세 §2. 카드 A그룹(P1~P7). 틀 §4B.
