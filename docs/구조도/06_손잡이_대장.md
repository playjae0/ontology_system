# 06 · 손잡이 대장 — 조절할 수 있는 것은 전부 여기 있다

> **무엇인가**: 사람이 돌릴 수 있는 것의 **전체 목록**이다. 증상이 없어도 「이 시스템에서 무엇을 어디서 바꿀 수 있나」를 이 한 장으로 본다. 고장이 났을 때 증상으로 찾는 것은 `05_조절_지도` · 가이드 §7이고, 여기는 **재고 목록**이다.
> **칸 번호**는 `00_칸_대장.md`. 지시문 9개 행은 회귀가 잠근다(파일 집합 == 대장) — 나머지 행은 사람이 유지한다: 손잡이를 더하거나 옮기면 **그 회차에 이 표를 고친다**(보고 양식의 「낡은 절 목록」 대상).
> **종류가 곧 「누가 바꾸나」다** — **지시문·config·자산**은 사내 운영자가 파일을 고쳐 바꾼다(코드 무관). **코드 상수**는 사내에서 손대지 않는다 — 값이 명세·가결정에 매여 있어 바꾸려면 회차(허브 요청문)로 간다. **실행 설정**은 환경마다 다르다.
> **최종 갱신**: 2026-09-15 (B64 마감 — columns 세 꼴 · 스탬프는 손잡이가 아님)

## 읽는 법

| Column | Meaning |
|---|---|
| Cell | 어느 칸의 판단을 바꾸나 |
| Kind | 지시문 · config · 자산 · 상수 · 설정 · 사람 입력 |
| Where | 실물 파일 경로 또는 `파일::이름` |
| Changes | 무엇이 달라지나 — 한 줄 |
| Effective | 언제부터 — 다음 등록 · 다음 인입 · 즉시 · 회차 |
| Check | 바꾼 뒤 무엇으로 확인하나 |

## 이 표가 말하지 않는 것

- **회귀 어서션·골든셋·계기판**은 손잡이가 아니라 측정 장치다 — 가이드 §5.4 · 04 「확인 루틴」.
- **`review/<dt>/`의 산출물**(`adapter.py`·`schema.json`·`input_package.json`·`state.json`·`interview_log.json`)은 손잡이가 아니라 생성 결과다. 고치는 길은 `--instruct`(1.3)와 `generate --revise`(1.8)뿐 — 파일을 손으로 고치면 다음 관문이 덮거나(`header_labels`·`adapter_version`) 승인 이력이 끊긴다.
- 상수를 회차 없이 사내에서 바꾸면 명세와 코드가 갈린다 — 문서 7 §7.4-5 「공용 코드의 사내 수정은 버전 기록과 외부 통보 없이 하지 않는다」.
