### 자체 검출

- 자체 검출 1: 재시도가 행의 극성을 몰라 좌표를 하강하지 않아 인입과 **다른 이름**을 세웠다 — `노칭::빔 출력`(재시도) ↔ `노칭::cathode::빔 출력`(인입) · 재구축이 그 값을 「대상 없음」으로 다시 판정했고 그래프도 갈렸다(③ 스모크에서 발견 — 대장만 갱신하면 ⓒ가 서지 않았다) → 표의 보류 행 재료에 `electrode_type` · 재시도는 행마다 `descend_anchor` → `anchor_polarity` → `resolve_at_home`.

- 자체 검출 3: 옛 기록을 지금 이름으로만 채우면 뒤에 개명·병합(canonical 지정)된 노드의 앞 연산이 재구축에서 「대상 없음」이 된다 → 뒤에서 걸으며 그때 이름(시험 ⓐ — 확인 뒤 개명 · `--canonical` 병합 포함 11/11이 B106 기록과 같다).
- 알려진 한계(이연 후보): 골격 닫힌 목록 스냅샷은 골격 노드의 **별칭 전부**를 싣는다(`bootstrap` 스냅샷 쓰기 — 인입의 LLM 매칭 · 사람 `ops alias`가 골격 노드에 붙인 별칭도) — 재구축의 `bootstrap`은 빈 그래프에서 스냅샷을 만들어 그 별칭이 없다. 재구축 전에 인입 뒤 `bootstrap`을 돌린 적이 있고 골격 노드에 그런 별칭이 있으면 재구축 안의 좌표 정확 일치와 null 기억의 판이 그 전과 달라진다(끝 보고 「태깅 n > 0」으로 보인다). mock 표본은 0(첫 인입 뒤 골격 노드의 seed 밖 별칭 0 · 인입 뒤 `bootstrap` 다시 → 판 같음 — `bfc003d32ec8bd6b`) · 사내는 미측. 처방 후보: 스냅샷의 별칭을 seed 출처로 한정 · 또는 재구축이 지우기 전 스냅샷의 별칭을 남긴다.
