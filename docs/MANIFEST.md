## 넣은 뒤 확인 (A0 전)

각 파일 머리의 `version:` 줄을 위 표와 대조한다. 특히 **틀 v2.4 / 카드 v11 / 증분0 v1.3 / 파서_명세 v0.5.1 / raw_mock v2.1**. 다르면 다시 내려받는다.

`docs/` 안 문서끼리도 대조한다(검사 5 — 반입 대조). 계수·판본·경로가 문서마다 다르면 그 자체가 결함 신호다. **13회차에서 판정된 9건은 CLAUDE.md에 반영되어 있으므로 재발의하지 않는다.**
