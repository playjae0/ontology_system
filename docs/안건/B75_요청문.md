# B75 구현 요청문 — 임베딩은 선택이다(없어도 돈다 · 켜고 끄고 비교한다) · 스코프는 정말 하드 필터다 · 비용은 실패해도 보인다 · 칸 3.4 · 3.1 · 0.4

> **수신**: 구현 세션 · **발신**: 허브 (2026-09-16 · 사용자 확정 2026-09-16) · **B74 뒤(`de7fbb5`)** · **출처**: 사내 실측 열넷째 — B73 코드로 첫 CP 인입(table · 조각 490 · 정확 일치 180 · 목록 밖 53종 · 행 310)이 **`③임베딩 — 실호출 경로가 비어 있다: EMBED_MODEL 미설정`으로 중단**. 첫 판정 호출 전이라 진행 줄도, 끝 요약도, 토큰 한 줄도 없이 끝났다. 사용자: 「임베딩 없어도 돌아가게 · 임베딩을 켰을 때와 껐을 때 차이를 보게 켜고 끄는 것을」.
> **진단 ①**: `core/matcher._narrow`는 후보가 상한(12)을 넘으면 실호출에서 무조건 `embeddings.embed()`로 가고, `embed()`는 `EMBED_MODEL`이 비면 `NotConfigured`를 던진다(문서 7 §7.6-B-4 「조용히 mock으로 떨어지지 않는다」 — 그 규율은 **판정 LLM**의 것이고, 임베딩은 후보를 12개로 고르는 보조 수단이다). 임베딩이 판정 정확도를 올린다는 측정은 없다(P7). 사내 게이트웨이에 임베딩 모델이 있을지 없을지와 무관하게 **인입이 서면 안 된다.**
> **진단 ②**: D-152 ①은 「스코프는 하드 필터」라 적었는데 실물은 아니다 — ⓐ 후보가 12개 이하면 `"그대로"`(다른 부모의 노드가 그대로 판정에 오른다 · 129행) ⓑ 같은 부모 아래 노드가 **0개**면 `if near:`를 지나 **다른 공정 전량**이 임베딩→판정에 오른다(137행). 새 공정의 첫 관리항목들은 답이 NEW로 정해져 있는데 임베딩과 LLM을 부른다 — 이번 사내 중단이 바로 이 갈래일 가능성이 크다(목록 밖 53종 · 새 공정 다수).
> **진단 ③**: 비용 화면(B72 ②·B73 ①)은 있으나 ⓐ 문서가 **실패로 끝나면** 토큰 줄이 없다(`ingest.py:485~488` — except가 `실패 —` 한 줄로 끝난다) ⓑ 판정 진행 줄은 `\r`로 같은 줄을 덮어써서(325행) 터미널 스크롤에 남지 않는다 ⓒ 단계 승인은 `--step`의 7단계뿐이고 비용이 쌓이는 **판정 단계 안에서** 값 N개마다 멈추는 자리가 없다.

## ① 임베딩은 선택이다 — 손잡이 하나 · 없으면 겹침 · 켜고 끄고 비교 (칸 3.4 · 0.4)

- **손잡이 `CANDIDATE_NARROW`** — 값 `auto`(기본) | `embed` | `overlap`. 자리는 설정(`llm.local.json`/`~/.onto/llm.json`/환경변수 — 문서 7 §7.6 표에 행 추가 · `core/llm.py::config()`가 읽는다 — 게이트웨이 설정과 같은 자리라 사내에서 한 파일로 끝난다)과 **인입 플래그 `ingest-file --narrow embed|overlap`**(플래그가 설정을 이긴다 — 한 문서만 바꿔 비교하는 용도).
  - `auto`: `EMBED_MODEL`이 있으면 임베딩, 없으면 겹침. **어느 쪽이든 인입은 선다.**
  - `embed`: 임베딩 강제 — `EMBED_MODEL`이 비면 지금처럼 `NotConfigured`(사람이 켰으니 시끄럽게).
  - `overlap`: 임베딩 있어도 겹침(정규화 문자 2-gram 교집합 비율 — mock이 쓰는 그 함수 `_overlap`, 실호출도 같은 함수).
- 겹침은 sha256 벡터(D-152 ②의 「가짜 확신」)와 다르다 — 실제 문자 기반이고 결정적이다. 문서 7 §7.5-1 대체 표의 「임베딩 → 겹침」 행은 mock 한정이었는데, 실호출의 폴백으로도 등재한다(허브가 명세에 씀).
- **화면**: 요약 줄(B73 ①)의 `임베딩 e`를 `좁힘 — 임베딩 e · 겹침 o`로 갈라 적고, `EMBED_MODEL`이 비어 겹침으로 돌았으면 머리에 한 줄 `임베딩 미설정 — 겹침으로 좁힌다(--narrow embed로 강제 가능)`. `llm-check` ⑥은 미설정을 **실패가 아니라 「미설정 — 겹침 폴백」**으로 보인다.
- **비교**: 재료는 이미 있다 — 판정 대장(B74 ②)의 `path`가 `embedding+judge`/`overlap+judge`로 갈린다. 같은 문서를 `--narrow embed`와 `--narrow overlap`으로 각각 인입(재인입은 회수 후 다시)하고 `show report <doc_id> --json`을 둘 저장해 비교한다. 이 회차가 만드는 것은 **`show report --diff <a.json> <b.json>`** 하나 — 값(locator·field·surface)마다 두 판정이 다른 행만 표로(경로·판정·node·후보 수·토큰) + 머리에 「다른 행 n / 전체 N · 토큰 a vs b」. 어느 쪽이 맞는지는 사람이 본다 — 도구는 차이만 보인다.

**완료판정 ①**: 어서션(성질) — `EMBED_MODEL` 비어 있고 `auto`면 인입이 끝까지 돌고 대장의 path에 `overlap+judge`가 있고 `embedding+judge`는 0 · `embed` 강제 + 미설정이면 `NotConfigured` · `overlap` 강제면 실호출 모드에서도 `embed()` 미도달 · 플래그가 설정을 이긴다 · 문서 7 §7.6-2의 9지점 도달성 어서션(③임베딩이 `NotConfigured`에 닿는가)은 `CANDIDATE_NARROW=embed`로 잰다(auto에서는 폴백이 정답이라 닿지 않는 것이 맞다 — 어서션을 지우지 말고 조건을 옮긴다) · `--diff`의 행 수 == 두 대장에서 판정 또는 node가 다른 값의 수 · mock 회귀 불변(mock은 원래 겹침).

## ② 스코프는 하드 필터다 — 부모가 다른 노드는 후보에 넣지 않는다 (칸 3.4)

D-152 ①을 실물로: 스코프 카테고리(`canonical_scope.bind_categories`)이고 `parent`가 있으면 **`_narrow` 이전에** 후보 풀을 같은 부모로 자른다 — 상한 이하 여부와 무관하게, 같은 부모 아래가 0개면 후보 0(→ `match`가 NEW · LLM 0 · 임베딩 0). 부모가 없는 값(좌표 미해소 행)은 지금 규칙 그대로(4.5-6 — 스코프 노드와 병합 금지). 요약 줄의 `스코프로 끝`은 「같은 부모 필터로 판정 없이 끝난 수(후보 0 → NEW)」를 따로 센다.

**완료판정 ②**: 어서션(성질) — 스코프 카테고리에서 판정에 오른 후보 전부 `parent == 값의 parent` · 같은 부모 0개면 LLM·임베딩 호출 0이고 verdict NEW · 부모 없는 값은 이전과 같다 · 회귀 그래프 불변(클린 2회 동일).

## ③ 비용은 실패해도 보인다 · 진행 줄은 남는다 · 판정 안에서 멈춘다 (칸 3.1)

- ⓐ **실패 시 토큰 줄**: 문서 단위 except(`ingest_file`)에서 `실패 — …` 다음 줄에 `이 문서까지 — LLM 호출 k · 토큰 t(입력 a · 출력 b) · 멈춘 단계 <선택|파싱|좌표|판정 값 i/N|부착>`. `ingest-dir` 총계 줄은 실패 문서의 몫도 합산한다.
- ⓑ **진행 줄은 새 줄**: `\r` 덮어쓰기를 버린다 — 보폭(10%)마다 새 줄. 로그 파일에도 같은 줄이 남는다(`onto.ingest` INFO).
- ⓒ **`--step-every N`**: 판정 단계 안에서 값 N개마다 멈춘다 — `[판정] 값 i/N · 호출 k · 누적 토큰 t · 남은 값 m → [계속 c / 멈춤 q]`. `q`면 **그 문서는 그래프 쓰기 0**(체크포인트는 남는다 — `--step`의 `q`와 같은 규칙 · 부분 쓰기 없음). `--step`과 독립이고 같이 줄 수 있다. 비대화형에서는 무시(한 줄). 판정 단계에만 둔다 — 비용이 쌓이는 단계는 그것뿐이다.

**완료판정 ③**: 어서션(성질) — 판정 도중 예외를 심으면 토큰 줄이 찍히고 그 수가 `llm.usage_total()`과 같다 · 진행 줄 출력에 `\r` 없음 · `--step-every 5`에서 `q`를 넣으면 그래프·사전·큐 쓰기 0 · 비대화형 무시.
