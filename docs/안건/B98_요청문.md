## 사내에서 사용자가 할 것 (참고 — B98을 기다리지 않는다)

`python run.py llm-check` → ①줄의 「설정 파일 <경로>」가 실제로 읽힌 파일이다 — 그 파일에 대문자 키로 `"EMBED_BACKEND": "local"` · `"EMBED_MODEL": "<모델 폴더 절대경로>"` → ⑥줄이 `embed local <폴더> — device · 로드 · 인코딩`이면 통과 · 셸 환경변수(`env | grep -E "EMBED|ONTO_CONFIG"`)가 파일을 덮지 않는지 확인 → 같은 `ingest-file` 명령을 다시 — `추출 — 체크포인트 재사용(LLM 0)`으로 구축만 간다. 급하면 `--narrow overlap`.
