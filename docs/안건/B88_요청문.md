## ① 엑셀 그림을 이미지 요약으로 (칸 2.1 · 2.2 · ④) — **먼저**(사내 RFQ가 이미 엑셀이다)

- **리더**: xlsx 그림을 **zip에서 직접** 읽는다 — `xl/worksheets/_rels/sheetN.xml.rels` → `xl/drawings/drawingN.xml`(앵커의 시작 셀) → `xl/drawings/_rels` → `xl/media/*`. openpyxl이 버리는 WMF·EMF도 여기서 잡힌다. 바이트는 **`raw["_images"]`에만**(PPT·PDF와 같은 규칙 — 계약 JSON에 바이트 0) · 시트별 `images`에 `{cell, ref, mime}`.
- **형식**: 모델이 받는 형식(png·jpeg)이 아니면 — WMF·EMF 등 — **`soffice`가 있으면 PNG로 변환**(`parser/render.py`의 기존 외부 프로그램 규칙 · 없으면 데이터로 남긴다). 변환 못 하면 지금의 한 줄에 사유를 붙인다: `그림 n개를 읽지 못해 건너뜀(WMF k — 변환기 없음)`.
- **산문 엑셀 어댑터**: **`prose` 시트의 그림만** 조각으로 낸다 — `image_ref` + `section`(그림이 앉은 행이 속한 청크의 section) + `context`(같은 청크 본문 앞부분 — PPT의 「같은 슬라이드 텍스트」와 같은 뜻). `ref` 시트 그림은 조각 0(참조 = LLM 0 그대로) · `skip`은 읽지 않는다. 표(table) doc_type의 그림은 지금처럼 다루지 않는다. 쪽 전체 렌더(PPT·PDF의 `page`)는 엑셀에 없으니 보내지 않는다.
- **예고**: 요약 전에 `그림 요약 — 새 n장 → LLM ≤ n회(보존 재사용 m)` 한 줄. mock이면 호출 0(고정 문자열 + `image_summary_source=mock` 그대로).
- **게이트웨이가 그림을 못 받으면**(`llm-check` ⑦ FAIL): 지금 ④의 동작 그대로 **그 문서만 문면 있는 실패**(C14 — 나머지 문서는 계속)이고 문면이 `llm-check` ⑦을 가리킨다. 그림 없이 넣으려면 **명시적으로** `--no-images` — 조용한 건너뜀은 없다 · 그 사실은 인입 기록과 `show doc`에 「그림 n장 요약 안 함(--no-images)」으로 남는다.

**완료판정 ①**: 어서션(성질) — 그림 든 산문 엑셀 표본에서 `prose` 시트 그림마다 image 조각 1 · `ref`·`skip` 시트 그림 조각 0 · 계약 JSON에 바이트 0 · 재인입 호출 0(보존) · WMF 표본: `soffice`가 있으면 요약 조각, 없으면 건너뜀 줄에 사유 · `--no-images`면 호출 0 + 기록 · **그림 없는 엑셀의 판독·분할은 바이트 동일**.
