## ① 어서션 감사 — 문면·중복을 세고, 세 조건이 증명된 것만 지운다 (칸 0.3)

- 화면 문면·중복은 **성질로 재조준**하거나(수 불변) 삭제한다 — 삭제는 CLAUDE.md §7 세 조건을 항목마다 적는다(읽는 곳 0은 어서션엔 해당 없음 → 「같은 성질을 다른 어서션이 잰다」 증명으로 대체).

## ② 자산 짝 맞추기 — 전시물과 표본은 관문을 지난다 (칸 1.5)

`kit/참조어댑터/cp.{py,json}`(few-shot 전시물)이 `CP01.xlsx`에 없는 K열(개정일 · role: meta — B72 ①의 few-shot 요구)을 내서 G26/G52 FAIL. 내장 참조 자산은 관문 대상이다(B73 ⑤ — 「비대상 예외를 두지 않는다」). 허브 판정: **표본을 맞춘다** — `tests/fixtures/raw/CP01.xlsx`와 등가 `CP01.csv`에 K열 「개정일」을 더한다(값은 행마다 같은 날짜 문자열 · meta라 그래프에 안 들어간다). 회귀의 노드·엣지 수(86·133 등)와 CSV 등가(B66 ⑤)는 **불변**이어야 한다 — 변하면 그것이 발견(보고).

**완료판정 ②**: 전시물 쌍 + `CP01.xlsx` 관문 전 구간 PASS · xlsx↔csv 등가 어서션 불변 · 회귀 그래프 불변(클린 2회) · 참조 자산 셋(cp·pfmea·ipqc) 전부가 회귀에서 **실행으로** 관문을 지난다(전시물이 회귀 밖에 있어 이 결함이 회차 둘을 살아남았다 — 어서션 하나로 상시).
