## ① 좌표 쌍의 다음 줄은 상위의 출처로 고른다 (칸 0.3)

- 처방 줄을 **한 함수**로 — 판정 전 쌍 화면(전제 1)과 큐 화면(전제 2)이 같이 부른다. 쌍의 상위가 어디서 왔는지(전제 3)로 고른다 — 문서 형태 · doc_type으로 가르지 않는다:
  - **행 상위**(표의 상위 열 — `GROUP`): 지금 줄 그대로(열 매핑 재등록 · 골격 · 별칭 · 쌍 확인).
  - **문서 좌표 상위**(`DOC_GROUP` — 행에 상위가 없어 문서 좌표로 잰 쌍): 「여러 공정을 다루는 문서면 문서 좌표를 상위 공정으로 다시(`python run.py ingest-file <문서> --doc-type <dt> --coord <상위 공정>`) · 표기가 다른 이름이면 골격 `ALIASES` + `python run.py bootstrap` · 이대로 두려면 쌍 확인(`python run.py platform queue coord_mismatch`)」 — 열 매핑 줄 0.
  - 둘이 섞인 화면은 종류마다 한 줄.
- 실경로 처방은 그대로 쳐서 도는 꼴(문서 경로 · doc_type이 있으면 채운다 — `revise_line`의 결).

## ② 원인 묶음 아래 「행 밖」 (칸 0.3 · 3.x)

- 못 붙은 행으로 세지 않는 **잃은 것**을 원인 묶음 아래 따로 — 행의 합(머리 · 원인 줄 · 목차 나무)에 섞지 않는다:
  - `관계 — 끝점 없음 '<이름>' · 못 선 관계 n · <위치>` + `▶ <처방>`(지금 `_endpoints`의 재료 · 처방 그대로 — 전제 4) — 위 원인으로 못 선 값의 이름은 빼고(지금 규칙).
  - `공정 표기 — 골격에 없음 '<표기>' · 조각 n · <위치>` + `▶ 골격 ALIASES에 그 표기 → python run.py bootstrap → python run.py ops relink all --doc <doc_id> --actor <이름>` — 좌표 행 보류(골격에 없는 좌표 · 좌표 목록 밖 — 전제 6) 중 **위 원인 줄의 「못 찾은 것」에 이미 든 표기는 뺀다**(그 표기 때문에 값이 못 붙었으면 원인 줄이 이미 말한다).
- 못 붙은 행이 0이어도 「행 밖」이 있으면 묶음이 선다(머리 「원인 묶음 — 못 붙은 행 0 / 전체 N」 + 행 밖) · 둘 다 0이면 묶음 0(지금 그대로).
- 인입 끝(위 `LIST_LIMIT`줄)과 `show report`가 같은 함수 · `--json`에 같은 재료.

## ③ 머리의 분모 (칸 0.3)

- 머리의 종류는 **전체가 0이 아닌 종류 전부** `a/A`(못 붙음 0이어도 — 보이는 분모 합 = 전체) · 상태(보류 · 고아 · 불확실)는 0이면 뺀다(지금 그대로).
