## ① config 지도 표기 (`cli/export_config.py` · `cli/config_map.py` · 뷰어 그리기 인자)

- **화면 낱말 = config 키 이름(영어)** · 한국어는 설명에만:

| 지금 | 바꿈 |
|---|---|
| 「층 process」 | `<process layer>` 머리 + 층마다 색 띠(같은 색이 그림 · 칩에도) · 좌표 층이면 설명 한 줄 「coord layer — 좌표 골격을 가진 층」 |
| 층 표 「카테고리 · 정의문 첫 줄」 | `categories` · 정의문 첫 줄 |
| 「출발 · 관계 · 도착 · 대칭」 | `src` · `rel` · `dst` · `symmetric` |
| 「항목 · 값」 — 골격 · uses · 관계 목록 · 위아래 쌍(이 층에 걸리는 것) · 극성 · 미러 · 렌즈로 쓰는 doc_type | `key` · `value` — `skeleton` · `uses` · `relations` · `pairs`(이 층에 걸린 것) · `polarity` · `mirrors` · `lenses (doc_type)` · 층 패턴에 없고 쌍에서만 오는 것은 표시 「pairs에서」 |
