## ② 그래프 — WebGL 렌더러(벤더링) · 색 축 · 엣지 토글 · 노드 상세 (칸 5.x)

- **렌더러**: sigma.js + graphology를 `static/vendor/`에 **고정 버전으로 벤더링**(파일명에 버전 · `LICENSE` 동봉 · `vendor/README`에 출처 URL·해시). 외부 URL 0(회귀가 `http`·`//cdn` 문자열 0을 잰다). 렌더러는 **인터페이스 하나 뒤**(`render({nodes, edges, highlight, paths, filters, onSelect})`) — 교체 가능. WebGL이 없는 브라우저면 한 줄 안내(canvas 폴백은 만들지 않는다 — 두 벌 유지 비용).
- 레이아웃: 결정적 계층 좌표(`part_of` 트리 · 층·tier·부모 순)를 기본, force 토글(같은 입력이면 같은 그림 — 사람이 위치로 기억한다).
- **색 축 라디오**(`layer · category · status · tier · polarity · made_by` · 기본 `category`) · 값에 결정적 색 · 범례에 값·수·견본 · tier 범례에 한 줄 「main/sub/detail = seed 중첩 깊이 · 사람이 적지 않는다(문서 3 §3.9-⑺)」.
- **엣지 유형 토글**(rel마다 · 기본 전부 켬 · 골격/문서 유래/cross 소제목) · cross는 점선 별색 · 「층간 연결 항상 표시」 체크(기본 켬).
- 필터 5축 + 문서 · 검색(canonical·alias·id 문자열 필터) · 노드 상세 패널(canonical·category·layer·status·tier·polarity·attrs·aliases(+provenance)·인접 엣지 클릭 이동 · **provenance → 문서·행 → `/raw/` 링크**) · `obsolete` 토글.

**완료판정 ②**: 어서션(성질 — headless: 서버 띄우고 정적·API 파싱 · 브라우저 의존 0) — vendor 파일 존재·버전 문자열·라이선스 · 외부 URL 0 · 색 축 기본값 `category` · 렌더러 호출 인터페이스가 하나(`grep`) · 노드 상세의 provenance가 `/api/doc`·`/raw/` 링크로 풀린다(링크 대상이 실재).

## ③ 질의 trace — `answer()` 계측 (칸 4.1~4.3)

- `cli/query.py::answer()`가 이미 부르는 `link → expand → collect_chunks → facts → generate` 각 자리에서 **계산된 값을 기록만** — 판단 로직 0 · 새 순회 0 · 저장 0. `--json`에 `trace` 키(기존 키 불변 · 사람용 텍스트 불변):
  ```
  "trace": {
    "intent":     "<코드가 이미 정한 질문 유형>",
    "linking":    [{"surface","node_id","canonical","layer","method": "dict|llm_fallback"}],
    "hops":       [{"label": "<query_traverse 규칙명>", "kind": "expand|cross|flow",
                    "nodes": [id…], "edges": [{"src","rel","dst","layer","bridge": bool}]}],
    "collection": [{"chunk_id","via_node","doc_id","source_locator","tier": 1|2,"rank","kept": bool}],
    "facts":      [{"key","text","used": bool}],     // used = ⑧이 되돌려 준 번호 · mock은 전부 true
    "answer":     {"text", "sources": [...]},
    "miss":       ["미해소 표기…"]
  }
  ```
- 스키마는 「trace 계약 단일화」 ㉠ — 플랫폼 화면·골든셋 측정이 같은 데이터를 본다.

**완료판정 ③**: 어서션(성질) — 스모크 12문항에서 `trace.linking` 노드 == `linked` · `hops` 엣지 전부 그래프에 실재·`query_traverse` 규칙 안 · 2홉 문항의 `hops` 길이 2 · cross 문항에 `bridge` ≥1 · `collection`의 `kept=false` 수 == `truncated` · `facts` 수 == 사실 채널 수 · trace 켜고 끄고 답·경로·사실 수 diff 0 · 실행 전후 `data/` 해시 불변.
