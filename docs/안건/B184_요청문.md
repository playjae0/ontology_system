## ⓪ Ctrl-C 뒤 멈춤 — 원인을 재고 원인을 고친다 (이연대장 행 「Ctrl-C 뒤 멈춤」(dr))

- **사건**: 전체 회귀에서 test_ingest_view ⓓ(품질 산문 판정 예고 관문에서 Ctrl-C)가 가끔 붉다 — 자식이 ^C 뒤 25초 동안 아무것도 내지 않아 pty 운전(전제 2)이 죽인다. 단독은 초록 · B183 기준 커밋 전체 회귀에도 6회 중 1회.
- **원인 재기**: 멈춘 자식이 무엇을 기다리는지 잰다 — 자식 환경에 `PYTHONFAULTHANDLER=1`을 주고, 기다림이 끝났을 때 죽이기 전에 `SIGABRT`를 보내 스레드마다 스택을 화면으로 받는다(시험 운전 한 자리) · 전체 회귀(병렬)에서 재현될 때까지 돌린다.
- **고치기**: 스택이 가리키는 원인을 고친다(예: ^C 뒤 끝나지 않는 일꾼 · 잠금 · 되돌림). **기다림을 늘리는 것은 원인이 부하로만 밝혀질 때만** — 그때는 수치와 근거를 보고에.
- **사람에게도 같은 일**: 사내에서 사람이 그 관문에서 Ctrl-C를 쳐도 같은 멈춤이 날 수 있다 — 고친 뒤 「멈춤 → 시작 전 그대로」 흔적 어서션(지금 ⓓ) 초록 그대로.

## ② 승격 · 합침 · 그대로 — 손 하나 (core 한 함수 · 화면 둘이 부른다)

| 처분 | 하는 일 | 이름 · id |
|---|---|---|
| **승격** | 골격 파일에 (부모, 이름) 줄을 쓴다 · 그 노드의 잠정 표시를 걷고 사람 고정(seed) · 부모 미정 · 단 미정이면 이때 사람이 정한다(부모 엣지는 그 부모로) · 출처 사람 | 이름 · 노드 id · 아래 노드 그대로 — 다음 `bootstrap`이 같은 노드로 본다(새 노드 0 · 두 벌 0 — 시험으로 잠근다) |
| **합침** | 그 표기를 고른 골격 노드의 골격 별칭(`ALIASES` — 사람 보증)으로 쓴다 · 잠정 노드는 그 노드로 합쳐질 대상 | 아래 노드 이름이 바뀐다 → **재구축 한 길**(화면이 「재구축이 필요하다 — `python run.py rebuild`」를 말한다) · 그 자리에서 이름을 고치는 둘째 길 0 |
| **그대로** | 쓰지 않는다 · 「봄」 표지만(다음 화면에서 접어 둔다 — 가결정) | 그대로 |

- 손은 하나 — `--step` 좌표 단계(③)와 인입 뒤 한 화면(④)이 같은 함수를 부른다. 좌표 학습 승격(`ops learn-promote`)과 같은 손으로 둘지 따로 둘지는 가결정(골격 `ALIASES`에 쓰는 자리는 한 곳이어야 한다).
- **극성 단 안내**: 승격 대상의 부모가 극성 단을 가졌거나 그 노드 아래 값에 극성이 있으면 화면에 한 줄 — 「극성 단을 열려면 골격 파일에 극성 줄 → `bootstrap` → `rebuild`(운영 런북 6)」.
- 골격 파일이 config 인라인(파일이 아님)인 층은 지금 학습 승격과 같은 문면으로 멈춘다(전제 7의 그 갈래).
