# B70 구현 요청문 — mock 자산은 운영 경로에 섞이지 않는다 · 등록부 결손은 조용히 넘기지 않는다 · 칸 0.2 · 3.1 · 1.7

> **수신**: 구현 세션 · **발신**: 허브 (2026-09-15) · **출처**: 사내 실측 열째 — main(B66~B69) 이식 뒤 `ingest-file` · `scan`이 **cp · pfmea · ipqc**(레포가 싣고 나온 내장 doc_type — 어댑터는 `tests/fixtures/adapters/`, 스키마는 `schemas/`)를 대조 목록에 띄웠고 사용자가 등록한 doc_type은 없었다. 사용자: 「mock이랑 비교 돌아가는 거 뭐야」.
> **진단**: 두 가지가 겹쳤다. ①**내장 소재지가 운영 경로에 늘 섞인다** — `cli/scan.py::ADAPTER_DIRS`(픽스처 어댑터 폴더)와 `core/registry.py::_builtin()`(`schemas/*.json`의 실재가 곧 등록)이 `USE_MOCK`과 무관하게 열린다. 코드 주석이 이미 「P트랙 이전의 잔재 · 등록이 쌓이면 자연히 비어 간다」고 적어 두고 방치했고, 허브가 B66 ④에서 「별도 판단」으로 미뤘다. ②**등록부 결손을 조용히 넘긴다** — `adapter_paths()`가 등록부 항목의 파일이 없으면 `if exists`로 건너뛴다. 등록 산출(`data/doc_types.json` · `adapters/<dt>.py` · `schemas/<dt>.json` · `review/<dt>/`)은 git 추적 밖이라 코드만 옮기면 안 따라오는데, 그때 화면은 「내장 셋만 있다」로 보인다.
> **원칙**: mock 트랙(`USE_MOCK=1` — LLM 없이 전 구간이 돈다, 문서 1 B12 · 문서 7 §7.5)은 남는다 — 회귀 1196건의 근거다. 걷어내는 것은 **mock 자산이 운영 경로에 섞이는 것** 하나다. 명세에 그 문장이 없었다 → 문서 7 §7.5에 한 줄(이번 zip · 허브).

## ① 내장 소재지·내장 doc_type은 `llm.use_mock()`일 때만 (칸 0.2 · 3.1)

- `core/registry.py::all_doc_types()` — `_builtin()`은 `llm.use_mock()`이 참일 때만 합친다. `USE_MOCK=0`이면 **등록부(`data/doc_types.json`)만이 doc_type의 전부다.** `lookup`·`schema_of`·`platform doctypes`가 전부 이 함수를 지나므로 자리는 하나다.
- `cli/scan.py::adapters()` — 기본 소재지(`ADAPTER_DIRS`)는 `llm.use_mock()`일 때만. `--adapters <경로>`로 사람이 준 경로는 그대로(명시는 의도다).
- 결과: 사내(`USE_MOCK=0`) 화면에 cp·pfmea·ipqc가 뜨지 않는다. 회귀(기본 `USE_MOCK=1`)는 그대로 돈다 — 조건 하나가 두 세계를 가른다.
- `registry.py`가 `core/llm.py`를 import하는 것은 경계 안이다(게이트웨이 설정 접근은 `llm`로 수렴 — 문서 7 §7.1). 파서(`parser/`)는 건드리지 않는다.

**완료판정 ①**: 어서션(성질) — `USE_MOCK=0`(env 주입 · 실호출은 안 한다 — `use_mock()`만 거짓이면 된다)에서 `all_doc_types()` 키 집합 == 등록부 키 집합 · `scan.adapters()` 파일 집합 == 등록부 어댑터 집합 · `USE_MOCK=1`이면 지금과 같다(회귀 전량 불변).

## ② 등록부 결손은 상태 거부 (칸 3.1 · 1.7)

`adapter_paths()`가 없는 파일을 건너뛰지 않는다. 등록부 항목이 가리키는 `adapters/<dt>.py` 또는 `schemas/<dt>.json`이 없으면 **scan·ingest 진입에서 상태 거부**(B61 계약 — 원인 + 다음 줄 + 잰 것):

```
[등록부] 'ipqc_real'이 가리키는 adapters/ipqc_real.py가 없다 (등록 2026-09-15 · 승인 홍길동)
  ▶ 다음 줄 — 이식이면 넷을 같이 옮긴다: data/doc_types.json · adapters/<dt>.py · schemas/<dt>.json · review/<dt>/
     아니면 등록을 다시 한다: python -m cli.register generate ipqc_real <층> <표본> --revise
```

`platform doctypes`에 실물 유무 열 하나(`adapter ✓/✗ · schema ✓/✗`). 결손이 있는 doc_type은 대조 목록에서 **빼지 않고 막는다** — 빼면 지금과 같은 「조용한 화면」이다.

**완료판정 ②**: 어서션(성질) — 등록부 항목의 파일을 지우면 scan·ingest가 상태 거부이고 문면에 그 doc_type 이름과 다음 줄이 있다 · 상태 거부 스캐너 미분류 0 · 계약 위반 0 · `platform doctypes`가 결손을 표시한다.
