## ① 산문 인입마다 구조 확인 md (칸 0.3 — 이연대장 ca)

- 구조 단계 한 자리(`structure_screen.gate` — 412)에서 **`--step`이 아니어도** `export/split_<doc_id>.md`를 쓴다(같은 함수 `split_report.write_md` · 내용은 화면과 같은 덩어리 · `--step`이면 지금처럼 시트마다) · 배치 · 재구축도 같은 길이라 다시 쓴다 · 구조가 없는 문서(표 · 고정 규칙 그대로)는 쓰지 않는다(지금 `write_md`가 None).
- 인입 화면에 md 자리 한 줄(이미 있는 줄이 있으면 그 줄).

## ② 같은 파일을 상대 경로로 다시 넣어도 멈추지 않는다 (칸 3.1 — cb)

- 견줄 때 **지금 친 경로는 작업 폴더 기준**으로 풀고, **기록의 표기만** 상태 루트 기준으로 되돌린다(`from_home`은 기록 쪽에만) · 같은 파일이면 상대 · 절대 · `./` · 심볼릭 링크와 무관하게 같다 · 다른 파일(같은 이름 · 다른 폴더)이면 지금처럼 멈춘다.

## ③ doctor 쓰기 탐침을 재는 자리대로 (점검 — bx)

- 탐침 둘: **운영 상태 폴더**(`$ONTO_HOME` — 인입 산출 · 등록 · 진실 · 작업)와 **코드 폴더**. 문구는 재는 자리 그대로 · 상태 폴더에 못 쓰면 NG(인입이 돌지 않는다) · 코드 폴더에 못 쓰면 경고 + 막히는 것만(`--regress --serial` · 파이썬 캐시 — 인입은 돈다) · 탐침 파일 이름은 실행마다(B131 ①) · 남기지 않는다.

## ④ 문서 (같은 커밋 — 항목마다)

- 명세 패치(있으면) · 가이드(운영 런북 · 인입 이해 가이드 — md가 늘 생긴다 · doctor 두 줄 읽는 법 — 사람이 치는 명령이 바뀌지 않으면 한 줄만).

**완료판정**(창작 표본 · mock):
ⓐ md: `--step` 없이 산문 인입 → `export/split_<doc_id>.md`가 생긴다(내용은 구조 확인 화면과 같은 함수) · 기본 fresh 재구축 뒤에도 있다 · 표 문서는 생기지 않는다.
ⓑ 경로: 같은 파일을 상태 폴더 밖 작업 폴더 기준 상대 경로로 다시 넣으면 멈추지 않는다(절대 경로와 같은 결과) · 같은 이름의 다른 파일은 지금처럼 멈춘다.

ⓓ 네 벌 `--base <반입 커밋>` A · B · C 전부 같다.
