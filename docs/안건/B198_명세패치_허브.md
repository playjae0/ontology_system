### 4_쓰기절차.md §4.5-4 (F1 봉인 문단)
지금: 4. **mirrors는 표시만 한다 — 판정은 polarity 필드 비교다**: 같은 부모(또는 부모가 mirror 쌍) + 이름부 동일 + polarity 반대 → 자동 페어링, 하향 연쇄. 값을 공유하지 않는다. 짝 없는 자식은 mirror_asymmetry 큐 — 단 **Tier1 seed의 단극성 인스턴스는 제외**(사람 보증 = 짝 없음이 의도). **재평가는 전 문서 인입 후 빌드 말미 1회다** — 문서 빌드 중에 돌리면 뒤 문서의 극성 노드를 못 봐 표면화가 한 빌드 지연된다(실측). 말미 패스가 다는 큐 항목의 doc_id는 None이다(문서가 아니라 그래프 전체의 조건이므로). 큐는 쌍 키로 중복 제거하고 대칭이 회복되면 제거한다(self-heal). LLM 불요. **자동 규칙이 만든 mirrors 엣지의 provenance는 `auto:mirror_rule`이다** — 표기가 정해져 있지 않으면 빈 값이 되어 evidence_lost 오검출이 상시 발생하거나, doc_id를 채워 재인입 회수 대상이 되면서 매 재인입마다 mirrors가 지워졌다 재생성된다.
바뀔: 4. **극성 짝 기구는 없다** — 짝 엣지 · 짝 비대칭 큐를 만들지 않는다(극성 노드가 없다)(B198).

### 4_쓰기절차.md §4.5 경계 (F1 봉인 문단)
지금: 경계: **극성 결합은 표기 편의가 아니라 노드 정체성 규칙이다** — cathode/anode 노칭 프레스는 다른 실물이고 다른 값을 갖는다. 극성 불일치는 판정에서 감점이 아니라 **후보 제외**다(정체성 규칙 — 극성 결합 canonical은 별개 노드이므로 같은 후보군에 둘 수 없다). **파서는 극성을 이름에 붙이지 않는다** — 결합은 조건을 확인한 에이전트만.

까닭: B198 극성 P1 — 극성은 값의 한정어 · 노드를 가르지 않는다 (결정_극성_값단)
