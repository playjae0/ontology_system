## ① `query --json` (문서 5 §5.2-6)

1. `cli/query.py` 진입: `--json`이 있으면 텍스트 대신 **JSON 한 덩어리**를 stdout에 낸다(`ensure_ascii=False`, 들여쓰기 없음). 모드 줄(`mode_line`)은 **stderr**로.
2. 묶음 = `answer()`의 `res` 그대로 + 둘:
   - `linked_nodes: [{layer, node_id, canonical}]` — `kept`에서. 기존 `linked`(문자열)는 그대로 둔다.
   - `answer: str` — `generate(res)`의 텍스트(mock이면 `render(res)`).
   - 직렬화 안 되는 값이 있으면 그 자리에서 고치되 **키 이름을 바꾸지 않는다**.
3. `run.py` 도움말에 `[--json]`.

**완료판정 ①**: ⓐ `run.py query "노칭 다음 공정은?" --json | python -m json.tool` 화면 ⓑ 스모크 12문항(`tests/fixtures/queries.json`)에서 **JSON의 `facts`·`chunks` 건수·`path`·`linked` = 텍스트 출력에서 센 값** — 어서션 ⓒ `--json`이 있어도 텍스트 경로의 회귀는 변화 0.

## ② `run.py viewer [--port N] [--no-browser]` (문서 7 시각화 3형태)

### 구조
- `cli/viewer.py` 파일 하나. `http.server.ThreadingHTTPServer` + 표준 라이브러리만. **CDN 0, pip 0.**
- **템플릿은 하나다**: `cli/export.py`의 HTML 생성을 `build_html(world, *, query_panel=False) -> str`로 빼고 `cmd_html`은 그것을 부른다(파일 저장), viewer는 `query_panel=True`로 부른다(서빙). HTML을 복제하지 않는다.
- 라우트: `/` → HTML · `/api/query?q=…` → ①의 JSON 그대로(같은 프로세스에서 `answer()`+`generate()`) · `/api/health` → `{mode, nodes, edges, layers}`. 그 밖은 404. **쓰기 라우트 없음** — 그래프·큐·사전에 쓰지 않는다.
- 기동: 빈 포트 자동 탐색(`--port` 우선) → 주소를 stdout에 찍고 `--no-browser`가 아니면 `webbrowser.open`. Ctrl+C로 종료. mock 관문 **비대상**(관측 창구 — doctor와 같음) 대신 **화면 머리에 `mock`/`실호출` 배지 상시**.

### 질문 패널 (우측)
- 입력 + 버튼(Enter) · 예시 5개 버튼(`"노칭 다음 공정은?"` · `"노칭 정밀도 규격 알려줘"` · `"노칭의 관리인자는?"` · `"버 이슈는 어느 설비에서?"` · `"수율 올리려면 뭘 봐야 해?"`).
- 응답 렌더: **경로 배지**(4값) · **링킹 칩**(`linked_nodes` — 클릭하면 그 노드로 화면 이동) · `[그래프 사실]` 목록 · `[문서 근거]` 목록(doc_id·section·source_locator 한 줄 + 원문) · 잘림 경고(`truncated>0`) · `note`. **두 채널은 시각적으로 분리**(색·제목). 실호출이면 `answer` 텍스트를 맨 위에.
- 진행 중 표시 · 에러(비200·타임아웃)는 사유와 함께.

### 하이라이트 (기존 캔버스에 덧붙임)
- JS 전역 `highlight = new Set()`; `draw()`가 `highlight`에 든 노드는 강조색 채움 + 굵은 테두리, 나머지는 dim(필터로 숨긴 노드는 그대로 숨김). 새 질의마다 비우고 `linked_nodes[].node_id`로 채운다. 스냅샷에 없는 id는 칩에 「그래프에 없음」 배지.
- **경로·확장 노드는 칠하지 않는다** — 시스템이 trace를 내기 전까지는 추정하지 않는다(플랫폼 PF11과 같은 원칙).

**완료판정 ②**: ⓐ `run.py viewer --no-browser` 기동 화면(주소·모드) ⓑ `curl "http://127.0.0.1:<port>/api/query?q=노칭 다음 공정은?"` 출력 = ①ⓐ와 같은 JSON(키 집합 어서션 — 테스트에서 서버를 빈 포트에 띄워 대조) ⓒ `/`의 HTML에 질문 패널·`highlight` 코드가 있고 `export html` 산출에는 **없다**(같은 템플릿, 플래그 하나) ⓓ 스크린샷: 단일 링킹 문항 · 극성 3노드 문항(`"노칭 정밀도 규격 알려줘"`) · 미스 문항(강조 0 + note) — 헤드리스 브라우저가 있으면 PNG, 없으면 그 사실을 적고 ⓑ·ⓒ로 판정 ⓔ `grep -rn "cdn\|https://" cli/viewer.py cli/export.py` → 0 ⓕ 회귀 유지 + 어서션 증가.
