## ① 층 자산은 상태 루트에 산다 — `$ONTO_HOME/layers/` (②등록 단) (칸 0.1 · 0.3)

- `layers/<층>/config.json`·`skeleton.json`은 **사람이 사내 공정 체계로 고쳐 `skeleton-confirm`으로 승인 1회 하는 것**이다 — 등록의 정의 그대로(재생성 불가 · 사내 정보). 자리는 `$ONTO_HOME/layers/`. `paths.layers()`가 자리 소유자이고 7곳이 그것을 부른다(`router.discover()` 포함 — 레포 고정 상수 삭제).
- **레포 `layers/`는 기본 seed(mock 검증 바닥)로 남는다** — mock 내장 스키마가 `tests/fixtures/schemas/`에 남는 것과 같은 지위. `init --fresh`(클린)가 레포 `layers/`를 **상태 루트 `layers/`로 복사**한다 — 그래서 `state_mock/layers/`는 언제나 레포 판이고 회귀는 그대로 돈다. 운영(`USE_MOCK=0`)은 `init --fresh`가 `layers/`를 **건드리지 않는다**(②등록은 클린 밖 — 문서 7 §7.6-4).
- `USE_MOCK=0`에서 `$ONTO_HOME/layers/`가 없거나 `config.json`이 하나도 없으면 **상태 거부** 「층 자산 먼저 — `platform migrate --assets --from <옛 코드 폴더>` 또는 `layers/`를 상태 루트로 복사」(근거 ④ 포함). 조용히 레포 seed로 떨어지지 않는다 — 그것이 바로 「코드 교체가 사내 골격을 mock 판으로 되돌리는」 사고다.
- `platform migrate`에 `layers/` 복사 추가(옛 코드 폴더 → `$ONTO_HOME/layers/`). **이미 이관한 사람용** `platform migrate --assets --from <옛 코드 폴더>`: `layers/`만 복사(상태 루트에 이미 있으면 해시 비교 — 다르면 덮지 않고 「다르다 — 사람이 정한다」로 멈춘다).
- `doctor` 첫 줄에 「층 k(상태 루트)」 · `doctor.py:469`의 문면을 새 자리로.

**완료판정 ①**: 어서션(성질) — `paths.py` 밖에 `layers` 경로 조립 0(grep) · `USE_MOCK=0` + 상태 루트 `layers/` 없음 → 상태 거부이고 문면에 경로 · `init --fresh`가 mock에선 레포 seed를 복사하고 운영에선 `layers/`를 건드리지 않는다(감시 파일) · 옛 배치 → `migrate` → 상태 루트 `layers/`의 해시 == 옛 코드 폴더 `layers/` · 회귀 초록 · 클린 2회 동일 그래프.

## ② 원본 문서의 자리 — `$ONTO_HOME/docs/` (칸 0.3 · 3.1)

- `paths.docs()` 신설(⓪원본 — 사람이 넣는다 · 시스템은 읽기만). `ingest-dir`이 인자 없으면 `paths.docs()` 전체(하위 폴더 재귀 · `--doc-type` 없으면 지문 스캔대로). `platform migrate`는 옛 코드 폴더에 `docs/`가 **있을 때만** 복사.
- **`doc_registry.source_path`는 상태 루트 아래면 `ONTO_HOME` 기준 상대 경로로 기록**(밖이면 지금처럼 절대) — 폴더를 옮겨도 기록이 낡지 않는다. 읽는 곳(`cli/ingest.py:467` 경로 비교 · `show doc`)은 `paths.home()`으로 되돌려 비교한다.
- 가이드 §0 표에 ⓪원본 행 · 백업 목록에 `docs/`·`layers/` 추가(문서 7 §7.8 표 · 상태_폴더_가이드 §2 — 허브).

**완료판정 ②**: 어서션(성질) — 상태 루트 아래 문서를 인입하면 `source_path`에 절대 경로 0 · 밖의 문서는 절대 경로 · 같은 문서를 옮긴 루트에서 재인입해도 「다른 경로」 경고 0 · `ingest-dir` 무인자가 `paths.docs()`를 돈다.

## ③ 실호출 갈래는 정적 검사와 스모크가 잠근다 · `import json` 정식 수리 (칸 0.4 · 2.8)

- ⓐ `core/llm/points.py`에 `import json` — 사내 임시 패치와 같다.
- ⓑ **미정의 이름 0 정적 검사**를 상시 회귀로 — `tests/exits_scan.py`처럼 **표준 라이브러리 AST**로(pyflakes 의존 0): 운영 모듈 전부(`core cli parser kit run.py doctor.py router.py`)에서 모듈 수준·함수 수준의 이름 참조가 import·정의·내장에 없으면 FAIL 문면 `파일:줄 이름`. 변이: `import json`을 빼면 붉다.
- ⓒ **실호출 갈래 본문 스모크** — 9지점의 실호출 함수 본문을 **실제로 한 번씩 실행**한다. 게이트웨이 전송(`gateway.chat`·`embeddings.embed`의 `_post`)만 스텁으로 갈아 끼우고(선례: `test_2a_gateway.py:108` ⑦), 각 함수가 반환 계약대로 값을 돌려주는지 잰다: ①추출 ②판정 ③임베딩(`CANDIDATE_NARROW=embed`) ④`summarize_image` ⑤생성 ⑥링킹 폴백 ⑦구조 지도(이미 있음) ⑧답변 ⑨`pick_coord`. 도달성 탐침(`require` → `NotConfigured`)은 그대로 두고 **그 뒤 본문**을 이것이 잰다 — 둘은 다른 성질이다.

**완료판정 ③**: 어서션(성질) — 미정의 이름 0 · `import json` 변이 붉음 · 9지점 본문 스모크 전부 PASS(스텁 응답으로 반환 계약 형태) · `pick_coord` 스텁 실행이 `canonical`을 돌려준다 · 회귀 수 증가는 이 셋뿐.

## ④ 루트 미설정은 화면이 말한다 · 자산은 레포 판인가 (칸 0.3)

- `USE_MOCK=0`인데 `ONTO_HOME`이 없으면 모드 줄과 `doctor` 첫 줄에 **「(ONTO_HOME 미설정 — 기본 루트 `<코드 폴더>/state`)」** 한 조각. 거부가 아니라 표시다 — 기본 루트로 쓰는 것도 정당한 배치다. 사내 실측: 새 터미널에서 `export`가 죽어 빈 루트를 보며 「가져온 게 사라졌다」로 읽었다.
- **레포 정본 자산의 사내 변경 감지**: `doctor`가 `prompts/`·`kit/`·`schemas/blocks.json`·(레포)`layers/`의 해시를 `docs/회귀스위트/자산/자산_해시.json`(구현 세션이 회차마다 갱신 — 회귀가 「레포 실물 == 기록」을 잰다)과 대조해 다르면 「⚠ 레포 정본 자산이 레포 판과 다르다 — <파일> · 사내에서 고치지 않는다(허브로 요청)」. 사용자 확정: 지시문·킷은 중간에 고치지 않고 최종 확정 뒤에만.

**완료판정 ④**: 어서션(성질) — `ONTO_HOME` 미설정 + `USE_MOCK=0`이면 모드 줄에 「미설정」 조각 · 설정되면 0 · `prompts/` 파일 하나를 변이하면 doctor가 ⚠를 낸다 · 자산 해시 기록 == 레포 실물.
