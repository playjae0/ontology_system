# B129 구현 요청문 — soffice 찾기 한 함수: PATH 밖 표준 설치 자리(macOS · Windows · Linux)와 사내가 지정한 한 자리까지 · 캡처 · 그림 형식 변환 · 환경 점검이 같은 것 · 칸 2.8 · 도구 · 문서

> **수신**: 구현 세션 · **발신**: 허브 (2026-10-20 · 사용자 결정 2026-10-20 — 「(B129를 B121 앞에 · 연달아) 진행해 보자」) · **B128 뒤**(`365360c`) · **가벼운 회차** · **같은 전달로 B121을 이어서**(마감은 따로 — B121은 이 회차 마감 커밋 위에서 전제를 다시 잰다).
> **출처 — 허브 확인(2026-10-20 · `365360c`)**: soffice를 찾는 자리가 셋이고 셋 다 PATH만 본다 — `parser/render.py` 47(`_soffice` — 캡처 판정 · 변환) · 194(`to_png` — 모델이 안 받는 그림 형식 변환이 따로 찾는다) · `doctor.py` 205(환경 점검). LibreOffice 기본 설치는 macOS(`/Applications/LibreOffice.app/Contents/MacOS/soffice`) · Windows(`%ProgramFiles%\LibreOffice\program\soffice.exe`)에서 PATH에 들어가지 않는다 → B128 뒤에는 제대로 깔아도 「soffice 없음」으로 실호출 PPT 인입이 파싱 전에 멈춘다. Impress 구성 요소 판정(`IMPRESS_LIBS` 65 — `.so` · `.dylib` · `.dll` · `program` · `Frameworks`)은 이미 세 OS를 본다 — 빠진 것은 「찾기」 하나.
> **원칙**: 찾기는 **한 함수**(캡처 판정 · 변환 · 그림 형식 변환 · 환경 점검이 같은 답) · 순서는 **PATH → 표준 설치 자리 → 사내 지정 한 자리**(지정이 있으면 그것이 먼저여도 된다 — 구현 판단 · 보고) · 못 찾으면 지금처럼 멈추고, 문구에 **찾아본 자리**를 낸다 · OS 이름으로 갈래를 늘리지 않는다(후보 자리 목록 하나 — 있는 것만 쓴다) · 시험은 실경로(찾기 · 변환을 가짜로 바꾸지 않는다).
> **명세와의 관계 — 개정 필요**: 문서 7 §7.6-B-6(선택 의존 — soffice를 찾는 자리). 바뀌어야 할 문장은 **명세 패치 파일**로.

## ① soffice 찾기 — 한 함수 (칸 2.8)

- 찾는 함수 하나(자리는 `parser/render.py` — 이름은 구현 판단): ⓐPATH(`soffice` · `libreoffice`) ⓑ표준 설치 자리 목록 — macOS `/Applications/LibreOffice.app/Contents/MacOS/soffice` · Windows `%ProgramFiles%` · `%ProgramFiles(x86)%` 아래 `LibreOffice\program\soffice.exe` · Linux `/usr/lib/libreoffice/program/soffice` · `/opt/libreoffice*/program/soffice` ⓒ**사내가 지정하는 한 자리**(이름 · 자리는 구현 판단 — 환경변수면 `ONTO_HOME`처럼 셸 설정 파일에 · 보고) → `(경로, 어디서 — PATH | 표준 자리 | 지정)` 또는 없음 + 찾아본 자리.
- `_soffice` · `to_png` · `doctor --env`가 이 함수를 부른다(셋째 찾기 0) · `capture_path`의 「빠진 것」 문구에 찾아본 자리(짧게).

## ② 환경 점검 · 문서 (도구 · 문서)

- `doctor --env`: `soffice 있음 — <경로>(PATH | 표준 자리 | 지정)` · 실제 변환은 지금처럼.
- `requirements.txt` · 운영 런북 · 2B 증상표 「캡처에서 멈춘다」 행: 표준 자리에 깔면 따로 할 것 없음 · 다른 자리면 지정하는 법 한 줄 · 구조도 02 PPT 절은 바뀐 몫만.

**완료판정**(실경로 — 찾기 · 변환을 가짜로 바꾸지 않는다 · 대표 사례 하나씩):
ⓐ 표준 자리: PATH에서 soffice를 뺀 하위 실행에서, 구현 환경의 표준 자리(예 `/usr/lib/libreoffice/program/soffice`)로 찾아 `capture_path`가 가능(soffice) · PPTX만으로 추출 호출마다 캡처 1장.
ⓑ 지정: PATH에도 표준 자리에도 없는 임시 폴더의 soffice 링크를 지정하면 그것으로 찾는다(같은 하위 실행 방식 — 표준 자리를 시험에서 가리는 법은 구현 판단 · 보고).
ⓒ 없음: 셋 다 없으면 사전 점검 「캡처」에서 멈추고 문구에 찾아본 자리.
ⓓ 한 함수: 그림 형식 변환 · 환경 점검이 같은 경로를 쓴다(ⓐ의 하위 실행에서 `doctor --env`가 표준 자리 경로).
ⓔ 네 벌: A · B · C 전부 같다.
