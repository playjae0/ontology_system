## ① `--instruct` 재생성분도 `machine_gate()`를 지난다

**왜**: 지시는 사람 것이지만 **산출은 LLM 것**이다. 관문을 안 지난 산출이 확정되면 「통과분만 확정」(B50)이 검수 지시 한 번으로 뚫린다 — 규약 10을 어긴 어댑터가 `--instruct` 한 줄로 등록부에 들어갈 수 있다.

**작업**:
1. `cmd_review`의 `if instruct:` 갈래 — `draft()` 뒤에 **`machine_gate(doc_type, st, samples, pkg)`를 그대로 부른다.** 생성 단계와 같은 함수·같은 해소 절차(자동 1회 → 문답 → `[y/N]`)다. 새로 만들지 않는다.
2. 관문을 통과 못 하면 **검수 뷰를 만들지 않고 끝낸다** — 생성 단계의 「검수로 넘어가지 않았다」와 같은 문면. `machine_gate` 상태는 FAIL.
3. 지시 이력의 자동 항목은 사람 지시 항목 **다음 번호**로 이어진다(`by: 자동(하네스)`) — 사람 지시 → 자동 해소가 한 사슬로 보이게.

**완료판정 ①**: ⓐ `review --instruct "…"`로 규약 10을 어기는 재생성을 유도(mock fixture `_rev1`이 위반본) → 하네스 FAIL → 자동 재생성 → PASS → 뷰 생성. 지시 이력에 `사람(검수 지시)` 다음에 `자동(하네스)` ⓑ 해소 실패 시 뷰가 안 생기고 `machine_gate=FAIL` ⓒ 회귀 유지 + 어서션 신설(변이: `machine_gate` 호출을 빼면 붉는다)
