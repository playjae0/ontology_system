## ① 그룹 경계 — 중간 저장 · 요약 줄 (`core/build/table.py` · `core/build/ledger.py`)

- 표 구축의 레코드 루프에서 **`process_group` 값이 바뀌는 자리**(구조 필드 — 층 어휘가 아니다 · 없거나 내내 같으면 경계 0 = 지금과 같다)마다:
  - 판정 대장을 **중간 저장** — `work/ingest_log/{doc_id}.partial.json`(머리에 문서 해시 · 쓰기는 원자적). 확정(구축 끝 `save`)하면 지운다.
  - 그룹 요약 한 줄(화면 손잡이 — core는 화면을 갖지 않는다): 그룹 이름 · 행 · 값 · 매칭/신규/불확실 · LLM 호출 · 골격 밖 공정 · 누계 — 수는 대장에서 센 것 그대로.
- 문서 끝의 마지막 그룹은 확정 저장이 겸한다(중간 저장을 따로 쓰지 않는다).

## ② `--step`이면 그룹마다 멈춤 (`cli/ingest.py` · `cli/ingest_screen.py`)

- `--step`(대화형)일 때만 그룹 경계에서 묻는다 — 계속 / `q`(멈춤). 멈춤 자리에서 **그 그룹의 판정 행**을 보는 길 한 줄(지금 있는 `show report <doc_id> --rows`가 중간 저장도 읽거나 같은 재료로 — 새 명령 0이 기본).
- `q` = 지금의 `Stopped`와 같은 되돌림(그래프 · 사전 · 큐 · 청크 시작 전 판 · 결과 `held`) — **중간 저장은 남는다**.
- `--step`이 없으면 묻지 않는다(요약 줄만) · 비대화형(파이프 · `ingest-dir`)도 묻지 않는다.

## ③ 다시 치면 재생 (`core/build/replay.py`)

- `begin`: 지난 확정 대장에 더해 **중간 저장**이 있으면 재료로 읽는다 — 문서 해시가 다르면 버리고 한 줄(「원본이 바뀌어 중간 저장을 쓰지 않는다」).
- 키 · 판정별 처분은 지금 그대로(B106 — 위치 · 열 · 표기 · 부모 좌표 · 층 · 카테고리) · **처음 인입이어도 중간 저장이 있으면 재생 대상**(명세 패치 ④) · 끝 줄의 재생 수에 그대로 든다.
