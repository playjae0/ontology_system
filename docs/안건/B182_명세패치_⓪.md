### 4_쓰기절차.md §4.3 규약 1 골격 카테고리
지금: **예외 — 골격 카테고리는 조회 전용이다**(B94 · D-175 · 사용자 확정 2026-10-01 「골격은 사람이 만든다」): 카테고리가 골격 카테고리(층 config `skeleton.category`)면 매칭은 그대로이고 **신규·불확실 갈래가 없다** — 골격 밖 표기는 노드 0 · `orphan_anchor` 큐(좌표가 골격 목록 밖일 때와 같은 사건 · 골격에 별칭이 생기면 재시도 배치가 항목을 거두고 그 행의 언급은 재인입이 붙인다) · 판정 대장 verdict `orphan`.
바뀔: **골격 카테고리의 신규 · 불확실은 잠정 골격 노드다**(B182 · 사용자 확정 2026-11-03 결정 A — B94의 「조회 전용」을 바꿈): 카테고리가 좌표 골격 카테고리(층 config `skeleton.category` · 겸 포함)면 매칭은 그대로이고 신규는 잠정 골격 노드(auto + 잠정 표시 · `auto_node` 큐) · 불확실은 잠정 골격 노드 + 합칠 후보(`uncertain_match` 큐)다 — 골격 파일은 사람의 승격만 늘린다 · 닫힌 분류(좌표 층 밖 골격)는 지금처럼 노드 0 · `orphan_anchor` 큐 · 판정 대장 verdict `orphan`.
까닭: B182 — 결정 A · D 표 · 개체 3분기와 같은 꼴(신규 = 잠정 · 불확실 = 잠정 + 합칠 후보 · 새 큐 종류 0)
