## ② 대장 잠금 — 코드와 `00_칸_대장.md`가 어긋나면 빨간불

- point 분리: 문답은 `point="interview"`(1.3), 생성은 `point="generate"`(1.4). 게이트웨이 설정(`core/llm.py`의 point별 모델·온도 표)에 `interview` 행 추가 — 값은 generate와 같게(동작 변경 0).
- 어서션 둘(성질):
  - **L칸 == 호출 지점**: 코드에서 `point="…"` 문자열을 모아 집합을 만들고, `00_칸_대장.md`의 L칸 행에서 `point \`…\`` 를 파싱한 집합과 같다(`chat`은 제외 — 0.4 게이트웨이 기본값). 대장은 파일로 읽는다 — 문면을 코드에 복사하지 않는다.
  - **지시문 == 파일**: 대장의 「Prompt / knob」 열에서 `prompts/…md` 경로를 모은 집합 == `ls prompts/`.
- 대장에 칸을 더할 때 코드가 없으면 빨간불이 아니다(C·H·G 칸은 point가 없다). 반대로 코드에 point가 생겼는데 대장에 없으면 빨간불 — **누락 방지 장치는 이 방향이다.**

**완료판정 ②**: ⓐ 어서션 2개가 초록 ⓑ 일부러 `point="foo"`를 한 줄 넣으면 빨간불이 나는 것을 보고에 붙인다(그리고 되돌린다) ⓒ `grep -c 'point="interview"' cli/interview.py` 2.
