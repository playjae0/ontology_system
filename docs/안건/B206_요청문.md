## ① 질의 — 답은 질문 바로 밑 · 못 하면 사유 (전제 2)

- 질의 탭 순서: 질문 → **ⓕ 답** → 결과 한 줄 → ⓐ~ⓔ 근거 → ⓖ 원 레코드.
- 결과 한 줄(trace에서 — 새 계산 0): `답함 · 쓴 사실 n · 쓴 조각 n · LLM(live)` 또는 `답 못 함 — <사유>`. **답 못 함** = 쓴 사실 0 이고 쓴 조각 0 · 또는 답 오류. 사유는 닫힌 셋에서 걸린 것 전부: 링킹 0(사전 미스 표기 함께) · 그래프 사실 0 · 근거 조각 0 · 상한에서 잘림 n · LLM 오류(문면) · mock(정형 나열).
- CLI `run.py query`도 같은 한 줄을 답 바로 밑에(같은 함수).

## ② 노드 상세 — 원 레코드 (전제 3)

- 노드 상세 패널에 「원 레코드(JSON)」 펼치기 — 그래프에 저장된 노드 꼴 그대로(값 항목마다 `value` · `context` · `provenance` · 극성 칸) · 질의 탭 ⓖ와 같은 자료(`/api/node`가 이미 주면 그것 · 없으면 그 라우트에 한 칸) · 기본은 접힘.

## ③ 잠정 노드로 「같은 것으로」 (전제 4)

- `m`의 대상 = 골격 칸 후보와 같은 셋(고정 ∪ 잠정). 대상이 잠정이면: 표기를 그 잠정 노드의 별칭으로(기록 — 재구축 재생 · 골격 `ALIASES`에는 쓰지 않는다 — 골격 파일에 노드가 없다) · 그 잠정을 승격하면 별칭도 `ALIASES`로 같이 간다.
- 후보 · 고를 곳 줄에 잠정이면 「(잠정)」.

## ④ 등록 문답 — 라운드마다 열 표 (전제 5)

- 문답 응답(지시문 1.3)에 열마다 판정 칸 — `[{열, role, 붙는 곳, 저장명, 맥락형}]`(엄격 규칙 · 지시문 판 올림).
- 라운드 화면: 진행 한 줄 → **살아남은 열 표**(열 · role · 붙는 곳 · 저장명 · 맥락형 · 이번 라운드에 바뀐 열 ✎) → **unmappable은 한 줄**(`제외 n열: 열 · 열 · …`) → 이해 요약 → 질문.

## ⑤ 생성 전 확정 확인 — 어느 길이든 (전제 6 · 7)

- 생성 직전 **한 자리**: 문답 · 힌트만 · 이어가기(y) 어느 길이든 확정 요약(④의 열 표 + 결정 항목)을 보이고 `[Y / 수정(번호) / 추가(문장)]` — 지금 `finalize`의 수정 고리 그대로 넓힌다(새 고리 0).
- 이어가기(y): 이전 확정 요약을 먼저 보인다 → 고칠 곳을 고친 뒤 생성(바로 생성 0).
- 비대화형은 지금처럼 확인 없이 간다(화면 한 줄).

## ⑥ 버리기(n)는 보관 — 새 판 확정 때 정리 (전제 7)

- n이면 이전 문답을 이번 입력에서 빼되 **보관**(묶음 `stale` 표지 — 지금 `_age_rounds`의 표지와 같은 꼴) · `confirm`이 새 판을 확정할 때 정리(보관 · 정리 수 한 줄) · 확정 전에 멈추면 이전 문답 그대로.
- 화면 문구: 「n이면 이번 입력에서 뺀다(보관 — 새 판 확정 때 정리) · 지금 등록은 확정 전까지 그대로」.
