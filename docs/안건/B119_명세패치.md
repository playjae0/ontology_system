### docs/spec/6_파서와구축모드.md §6.4 규약 5 — 산문 시트마다 문서 구조(고정 규칙은 초안)
지금: **규칙이 못 세우는 시트만 LLM 규칙 선언**([개정] B87 ② · D-168 ④⑥⑦⑧⑨ 확정): 고정 규칙 뒤 **제목 0 또는 레벨 비단조**인 시트만 ⑦ 지점의 호출 태그 `struct_rule`(지시문 `prompts/2.4_struct_rule.md`)로 규칙을 **데이터로 선언**받아 고정 어댑터가 적용한다 — LLM이 코드를 짜지 않는다(문서마다 사람 확인 없는 코드 실행은 관문 우회다). 입력은 시트 앞 `RULE_SAMPLE_ROWS` 비어 있지 않은 행의 글(80자) · 굵게 · 들여쓰기 · 가로병합 시작(글자 크기는 리더가 내지 않아 보내지 않는다 — 리더 산출을 바꾸면 등록 입력 패키지의 재현 조건이 흔들린다). 선언은 strict 스키마(`heading_patterns[{match, level}]` · `bold_is_heading` · `merge_is_heading` · `heading_column` · `reason`)이고 검증(정규식 컴파일 · `^` 시작 · 길이 ≤ 120 · 패턴 ≤ 8 · 레벨 1~6)을 못 넘으면 버린다. **보존**: 구조 지도 보존 파일의 `rules[<시트>]` + 원본 해시 — 같은 파일 재인입은 호출 0 · 같은 경계. **선언이 안 서면 구판의 길**이다 — 제목 0이면 통째 + `hierarchy_unresolved`, 비단조면 고정 규칙 분할(모드는 비용만 바꾸고 분할을 바꾸지 않는다). `ref` 시트는 대상이 아니다. 등록 리허설·킷 관문은 선언을 주입하지 않고 시트마다 「고정 규칙으로 선다 / 인입 때 선언 필요」만 보인다 — **산문이라는 근거(형태 판정 prose 또는 사람의 답)가 있으면 계층이 안 선 표본도 고정 어댑터로 등록한다.** 이미 등록된 위임 래퍼는 `extract`의 주인 모듈에서 선언 대상 프레임을 찾는다(래퍼 재생성을 요구하지 않는다). 재사용 판정은 추출 체크포인트의 `doc_hash`(청크 내용의 해시) 그대로다 — 분할이 바뀐 문서만 재추출되고 기본 어댑터 판본(1.0)은 올리지 않는다.
바뀔: **산문 시트마다 LLM 문서 구조 — 고정 규칙은 초안이다**: 산문 시트(`ref` · `skip` 제외 · 엑셀과 Word 한 함수 `parser/struct_rule.frame_chunks`)마다 지점 ⑪의 호출 태그 `structure`(지시문 `prompts/3.3_outline.md` — 제목 목록 호출과 한 지시문 · 한 스키마)가 **무조건** 제목 줄을 세운다. 입력은 시트 전체의 **줄 이름표**(행 · 앞 `LABEL_CHARS`자 · 표시 — 굵게 · 들여쓰기 · 병합 · 번호 꼴 · 다른 열)와 **고정 규칙의 초안 단** · 층의 닫힌 카테고리 · 정의문이다(본문 값 0 · 긴 시트는 `LINES_PER_CALL`줄씩 나눠 부르고 뒤 묶음에 열린 제목을 싣는다 · 렌즈가 여럿이면 층마다의 카테고리를 합친다). 출력은 제목 줄마다 부모 줄 · **역할**(닫힌 다섯 — 설비 · 유닛 · 사양 묶음 · 항목 · 주제) · 대상이면 이름(줄 글자 그대로의 일부)과 카테고리다. 검사는 결정적이다 — 목록 밖 줄 · 역할 밖 · 앞에 없는 부모는 그 줄만 초안으로 · 글자 밖 이름 · 목록 밖 카테고리는 대상만 버린다(결함 로그) · 호출이 실패하면 그 시트는 초안 그대로(보존 0 · 화면에 수). 분할 레벨은 크기로 고른 레벨과 **설비 · 유닛 · 사양 묶음 줄의 가장 깊은 단** 중 깊은 것이다 — 같은 유닛 아래 청크는 전부 경로에 그 유닛을 들고 조각마다 `meta.structure`(경로의 제목 줄마다 역할 · 대상)를 진다. **보존**: 구조 지도 보존 파일의 `structure[<시트>]`(원본 해시 · 이름표 해시 · 지시문 판 · 층 config 판) — 같은 파일이면 호출 0 · 같은 경계 · 재구축 재생 · 등록 리허설도 같은 함수다(구축 모드 3단 관문은 주입하지 않는다). **사람의 고침**은 등록 단 `registry/structure_fixes.json`(줄의 역할 · 대상 — 단은 그대로)이 보존분 위에 덮는다(`--step` 구조 표 · 재구축이 재생). 약한 구조 신호(설비 · 유닛 0 · 초안과 경계 · 단 수가 다름 · 글자 상한에서 잘린 청크 · 호출 실패 · 버린 줄)는 화면에 늘 · `--step`이면 구조 표로 묻고 · 비대화형은 진행하되 인입 기록과 `show summary`에 남긴다. 고정 규칙으로 안 선 시트의 계층 규칙 선언(⑦ 태그 `struct_rule`)은 운영 주입에 없다 · mock은 힌트 `<doc_id>@structure.json`만(없으면 고정 규칙 그대로)(B119)
