## ② 단계 1b — 5단 배치 · mock 자리 분리 · 이관 (태그 `B78-1b`) (칸 0.4 · 0.3)

**배치(기본 `./state` — `ONTO_HOME`이 있으면 그 아래)**
```
$ONTO_HOME/
  llm.json                      ← 설정 (기존 3자리 우선순위 뒤 넷째 · llm.local.json은 그대로 읽힌다)
  registry/                     ← ②등록 — 사람 승인 1회 · 재생성 불가 · 백업 1순위
    doc_types.json · adapters/<dt>.py · schemas/<dt>.json · review/<dt>/
  data/                         ← ③진실 — <층>/graph.json · dictionary · chunks · review_queue · doc_registry · ops_log
  work/                         ← ④단계 산출·장부 — parsed/ · extract/ · ingest_log/ · gate_rejects · *.log
  export/  golden/              ← ⑤파생 · 골든셋
```
- **mock은 자리로 가른다**(사용자 확정 2026-09-17): ⓐ mock 자산 전부 `tests/fixtures/` 아래 — 내장 스키마 4종을 `schemas/` → `tests/fixtures/schemas/`(레포 `schemas/`에는 공용 블록만 남는다) · `_builtin()`은 그 자리를 읽는다 · B70의 모드 가드(`use_mock()` 분기)는 **경로 가드**로 대체(등록은 `registry/`만 · 내장은 픽스처 폴더만 — 섞일 자리가 없다). ⓑ **mock 실행 결과는 `USE_MOCK=1`이면 상태 루트가 `./state_mock/`**(`ONTO_HOME`을 무시) — 운영 상태에 한 바이트도 쓰지 않는다. 회귀·doctor·`init --fresh`는 전부 `state_mock/`에서 돈다. 모드 줄(`모드: mock(기본)`)에 상태 루트 경로를 같이 찍는다.
- **등록부는 `registry/` 기준 상대 경로**로 저장한다(루트 무관). 옛 항목(`adapters/cp2.py`)은 이관이 재작성한다.
- **이관 `python run.py platform migrate [--from <옛 루트>] [--to <새 루트>]`**: 옛 배치의 넷(등록·진실·작업·설정)을 새 5단 자리로 **복사**(옛 폴더 보존) · 등록부 경로 재작성 · 이관 로그(`work/migrate.log` — 무엇을 어디로, 해시). 이관 뒤 `platform doctypes` 역방향 대조(B77 ③)가 0건이어야 한다.
- **옛 배치 감지**: 레포 루트에 `data/doc_types.json`이 있고 `state/`(또는 `ONTO_HOME`)가 비어 있으면 다른 명령은 **상태 거부**「이관 먼저 — `platform migrate`」(근거 ④ 포함). 조용히 옛 자리를 읽지 않는다.
- `init --fresh`는 `data/`·`work/`만 지운다 — `KEEP_IN_DATA` 예외 삭제(등록이 다른 폴더라 예외가 필요 없다). `.gitignore`: `state/` `state_mock/`.
- `doctor` 첫 줄: `상태 폴더 <경로> · 모드 <mock|실호출> · 등록 n종 · 층 k · 문서 m`.
- 체크포인트 재사용 조건(허브 검토 항목): `work/extract/<doc_id>.json` 재사용은 `doc_hash`와 **`adapter_version`이 둘 다** 같을 때만 — 어댑터 `--revise` 뒤 옛 추출을 재사용하는 길을 막는다.
- 어서션(성질): 옛 배치 → `migrate` → 그래프 해시·등록부·사전 동일 · 이관 전 실행은 상태 거부 · `USE_MOCK=1` 실행이 `state/`·`ONTO_HOME`에 쓰지 않는다(변이: 운영 루트에 감시 파일) · 레포 `schemas/`에 `doc_type` 키를 가진 파일 0 · 등록부의 경로에 `..`·절대 경로 0 · `KEEP_IN_DATA` 참조 0 · 회귀 초록(`state_mock/`) · 사내 조건 스위트.
