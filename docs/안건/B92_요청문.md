> **수신**: 구현 세션 · **발신**: 허브 (2026-10-01 · 사용자 확정 2026-10-01) · **B91 뒤** · 작은 회차.

## ① 카탈로그 맞추기 — `bootstrap` 입구 (칸 0.1)

`bootstrap`이 층을 심기 **전에** 층 config들(`categories`)과 `common.json`을 맞춘다. 규칙은 닫힌 다섯이다.

| 경우 | 처리 |
|---|---|
| 카탈로그에 없는 카테고리를 **한 층만** 선언 | **자동 추가** — `home` = 그 층 · 화면 `[bootstrap] 공통 config + 'X' (home 층A — 층A만 선언)` |
| 카탈로그에 없는 카테고리를 **여러 층이** 선언 | `home` **빈칸**으로 추가하고 **멈춘다** — 「선언한 층 [A, B] 중 하나로 채운다」(지금 ⓒ 빈칸 문면) |
| 카탈로그에 있는데 **어느 층도 선언하지 않는다** | 그 집 그래프에 그 카테고리 노드가 **0이면 자동 제거**(화면 한 줄) · **있으면 멈춘다** — 「노드 n개가 남아 있다 — 층 config에 되살리거나 재빌드」 |
| 카탈로그에 있고 선언도 있다 | **건드리지 않는다**(`home`·`also`는 사람 값) — 지금의 ⓒ(집이 선언 층 밖) · ⓔ(겸 형식) 검사는 그대로 |
| **처음**(파일 없음 · 운영) | 같은 규칙으로 **`common.json`을 바로 만든다**(한 층 → 그 층 · 여럿 → 빈칸) · `canonical_scope`는 지금처럼 층 config에서 옮긴다(ⓓ 「층 config에서 지운다」는 그대로) · 빈칸이 있으면 멈춘다. **`common.draft.json`은 더 쓰지 않는다** — 남아 있으면 「쓰지 않는 파일이다(지워도 된다)」 한 줄(지우지 않는다) |

- **변경이 있으면** `common.json`을 원자 쓰기(store)로 저장하고 `common_version`을 올린다 · `work/logs/bootstrap_<날짜>.log`에 무엇을 왜 바꿨는지(층 선언 근거) 남긴다.
- **미리보기** `python run.py bootstrap --dry-run` — 맞추기 계획(더할 것 · 물을 것 · 지울 것 · 멈출 것)만 보이고 **아무것도 쓰지 않는다**(층 심기도 0).
- mock 루트도 같은 규칙이다(레포 `layers/common.json`이 이미 맞아 변경 0). mock에서 파일이 없을 때의 「그 자리에서 세운다」(D-171 ①)는 그대로 둬도 되고 이 규칙으로 합쳐도 된다 — 네 벌 diff 0이면 구현 판단.

## ② 이미 노드가 있는 카테고리의 집 변경을 막는다 (칸 0.1)

- 사람이 `common.json`에서 `home`을 바꿨는데 **옛 집 그래프에 그 카테고리 노드가 남아 있으면** `bootstrap`이 멈춘다 — 「'Unit'의 home을 A → B로 바꿨지만 A 그래프에 Unit 노드 n개가 있다 — 재빌드(`init --fresh` → `bootstrap` → 재인입) 또는 home을 되돌린다」. 옛 집은 **카테고리 노드가 실제로 있는 그래프**로 판정한다(이전 값을 따로 저장하지 않는다).
- 노드 수를 세는 자리는 GraphStore 경유(접근 경계) — 카탈로그 모듈이 그래프 파일을 직접 열지 않는다.
