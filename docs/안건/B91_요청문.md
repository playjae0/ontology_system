## ① 렌즈 — doc_type의 층 목록 (칸 1.x · 3.3)

- **등록부**: doc_type 항목에 `lenses`(층 목록 또는 `"all"`). 없으면 `[layer]`(지금과 같다). 등록 때 줄 수 있고(`generate`) 나중에 바꿀 수 있고(작은 명령 하나 — 모양은 구현이 정한다 · 원자 쓰기) `register status`·`show schema`가 보인다. 목록의 층은 실재해야 한다(없으면 거부).

- **추출**: 청크마다 렌즈마다 **그 층의 어휘**(카테고리 정의문 · 관계 · 겸 한 줄)로 추출한다 — 한 번에 전 어휘를 주지 않는다(사용자 확정 — 한 번에 다 보면 놓친다). 개체는 집에서 해소(B90 그대로) · 엣지는 그 렌즈의 층에. 체크포인트 키에 렌즈가 든다(같은 청크 · 다른 렌즈 = 다른 체크포인트).

**완료판정 ①**: 한 층 = 네 벌 diff 0 · 테스트 세트 — `lenses: [process, quality]` prose 문서에서 두 렌즈의 개체가 **같은 노드로 모인다**(B90 전역 해소) · 관련성 0인 청크는 그 렌즈 LLM 0 · 예고 줄 · 상한 초과 멈춤.

**완료판정 ②**: mock 사람 지정 모드 — 기본 제안이 `ref`로 바뀐 것 외에 기록·산출 불변(바뀐 제안 목록 보고) · 자동 모드 — 테스트 표본에서 합의 시트 자동 · 불일치 시트 `ref` + 승격 후보 · 기록 네 필드.

## ③ prose 좌표를 셋으로 (칸 3.3 · 3.4)

- **주 좌표**: 지금 것 그대로(제목 경로 0~1개 · 이름 접두와 극성의 기본).
- **개체별 부모**(새): 추출 출력 entity에 선택 필드 `parent`(골격 canonical — 부모 후보 **안에서만** · 고르지 못하면 null). **부모 후보 = 좌표 서브트리 + 청크 본문에 나오는 골격 이름**(사전 스캔 — 결정적 · 전 골격을 넣지 않는다). 해소 순서: `parent`가 있고 골격 노드로 해소되면 그것이 이름 부모(주 좌표를 이긴다) → 없으면 주 좌표. **이름을 정하기 전에** 본다(지금은 이름 → 부착 순서).
- **관련 링크**(새): 추출 출력에 청크 단위 선택 필드 `about`(표면형 + 카테고리 · 0~N · 렌즈 카테고리 안). **조회 전용** — 사전·그 청크의 해소 결과로 찾고 **노드를 만들지 않는다**(못 찾으면 버리고 기록). 저장은 `data/chunks.json`의 두 번째 매달림(`describes` 옆 · 이름은 구현이 정한다).
- **추출 출력 스키마**: 두 필드는 **선택**이다 — 옛 체크포인트는 「없음」으로 읽는다(재추출 강제 0 · 사람이 원할 때 재추출). 지시문 판 올림(e-1.3) · 템플릿에 층 어휘 0.
- **근거 수집 순위**: `describes`(직접 > 확장) 앞 · 관련 링크(직접 > 확장) 뒤 · 상한은 손잡이(지금 8).

**완료판정 ③**: 새 필드 없음 = 네 벌 diff 0 · 테스트 세트(추출 힌트로 두 필드를 준다) — ⓐ 「3. 스태킹」 아래 「전 공정(노칭)의 버」 → `노칭::버` ⓑ 제목 「주간 이슈」 청크가 노칭·스태킹 양쪽 질의의 근거로 잡힌다(관련 링크 · 순위 describes 뒤) ⓒ 부모 후보 밖 이름은 null 처리 ⓓ 없는 노드를 가리키는 관련 링크는 노드 0 · 기록.
