## ① 추출 예고 (칸 3.3 · 화면)

- 추출을 부르기 **전에** 한 줄 — 렌즈 수와 무관하게(한 렌즈 포함): `추출 예고 — 청크 N(ref 시트 r · 체크포인트 재사용 k 제외) → LLM ≤ m회`. 렌즈가 둘 이상이면 지금의 렌즈 예고가 같은 자리를 맡는다(두 줄 중복 0).
- 체크포인트가 완전히 재사용되면 `추출 — 체크포인트 재사용(LLM 0)` 한 줄.

## ② 청크별 메타 줄 + 30초 누적 (화면)

- 청크 하나가 끝날 때마다 한 줄: `[추출 i/m] <source_locator> · 개체 k: 이름[카테고리] · … · 관계 r · 부착 a · 부모 p · 토큰 t` — 개체는 **전부**(표기와 카테고리), 관계는 수(관계 쌍은 명령 로그 `work/logs/<명령>_<날짜>.log`와 체크포인트) · 실패 청크는 `✗ 실패 — 사유`.
- **30초마다 누적 한 줄**(LLM이 도는 동안 · 한 호출이 오래 걸려도 — 시간 기준): `── 30초 · i/m · 호출 n · 토큰 n · 경과 m분 s초`. 한 자리(공용 함수)에서 내고, LLM을 오래 부르는 다른 단계(계층 규칙 · 그림 요약 · 좌표 태깅 · 판정)에도 같은 함수를 건다 · 수는 게이트웨이 누계 그대로.
- 끝 줄: `추출 끝 — 청크 m · 개체 · 관계 · 실패 · ` + `usage_line`.
- `cli/extract`(추출만)도 같은 화면. 비대화형(파이프)에서도 같은 줄(묻지 않을 뿐).

## ③ 청크 단위 이어 쓰기 (칸 3.3)

- 추출 중에는 청크가 끝날 때마다 **부분 파일**(예: `work/extract/<doc>[@렌즈].partial.json` — 이름은 구현 판단)에 원자 쓰기로 이어 쓴다 · 전 청크가 끝나면 최종 체크포인트로 올리고 부분 파일을 지운다 → 「파일 존재 = 추출 완료」 불변.
- 재실행: 부분 파일이 있고 재사용 조건(문서 해시 · 어댑터 판 · 렌즈)이 같으면 **끝난 청크는 부르지 않고 이어서** 한다 · 조건이 다르면 버리고 로그 한 줄 · 화면 `추출 이어서 — 끝난 청크 k · 남은 m`.
- 실패 청크(`failed`)는 이어 쓰기에서도 실패로 남는다(재시도 정책은 지금 그대로).

## ④ `--step` 산문 관문 (화면 · 칸 3.3)

- 산문 문서의 `--step` 관문: 파싱 → 좌표 → **[추출 예고 — 청크 N → LLM ≤ m회 · 계속/멈춤]** → 추출(② 화면) → **[추출 결과 + 판정 예고 — 개체 k · 표기 s종 · 사전 히트 h → LLM ≤ j회 · 계속/멈춤 — 여기서 멈추면 그래프 쓰기 0]** → 구축.
- 지금의 관문 3(레코드로 센 판정 예고)은 **표 문서에만** 쓴다 · 산문의 판정 예고가 단계 모드에서 숨는 자리를 고친다(산문은 추출 뒤 관문이 그 줄이다).
- 추출 뒤에서 멈추면 체크포인트는 완료로 남는다 → 같은 명령을 다시 치면 추출 재사용(LLM 0)으로 구축만 간다 · 멈춤 문면에 그 다음 줄.
