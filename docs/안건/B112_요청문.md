## ① 단위별 맞춤표 (칸 3.x — 결과 화면 · `show report` 같은 함수)

문서 끝(인입 · 재구축 · `show report`)에 **줄마다 단위**를 적고 **같은 단위는 합 = 전체**:

```
청크(산문)   N = 부름 a + ref b + 거름 c + 재사용 d          ·  부름 a = 개체 있음 + 개체 0 + 실패
조각 좌표    N = 자기 + 문서 좌표 + 학습 + LLM 태깅 + 없음     (무시 · 공유 건너뜀은 표시 — 합 밖)
값(개체 행)  N = 사전 + 재생(일치 · 새 · 불확실) + LLM 일치 + 새 노드(LLM 판정 · 후보 없음) + 불확실 + 보류(사유별) + 그 밖(경로 이름)
보류(행 종류별) 좌표 행 n · 개체 행 m · 소속 행 k  — 사유별
부착(개체)   N = 소속 엣지(대상: 공정 · 유닛·부품) + 관계만 + 좌표 폴백 + 엣지 없음
그래프       층마다 노드 · 엣지  전 → 후 (이 문서 +n)
큐           종류별 이번 n종(m행) · 이전 n종(m행)
```

- `값` 줄은 대장의 개체 행 **하나가 칸 하나**에 든다 — (판정 · 경로) → 칸의 닫힌 표 · 표에 없는 조합은 `그 밖(경로 이름)`으로 **보이게** 남긴다(사라지는 몫 0).
- 합이 맞지 않으면 그 줄 아래 `[결함] <줄> 합 x ≠ 전체 y`(로그에도) · 회귀가 표 · 산문 × 층 둘 · 재구축(재생)에서 합을 잰다.
- 성공 줄의 `그래프 노드 n`은 「이 문서 +n (그 층 전체 m)」로 — 총수만 두지 않는다.
