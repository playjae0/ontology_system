# B80 구현 요청문 — 게이트웨이 요청의 손잡이(`CHAT_TEMPERATURE` · 비우면 안 보낸다) · 임베딩 백엔드 `gateway | local`(로컬 모델 폴더) · 요청 조립은 한 자리 · 오류 문면은 URL을 말한다 · 원본 자리 이름 `docs/` → `raw/` · 칸 0.4 · 0.3

> **수신**: 구현 세션 · **발신**: 허브 (2026-09-22 · 사용자 확정 2026-09-22) · **B79 뒤(`5c09585`)** · **출처**: 사내 실측 — 새 모델(5.6luna)을 게이트웨이에 붙이니 **`temperature`가 실려 있어 막혔다**. 코드는 `temperature=0`을 **모든 요청에 고정으로** 싣고(`gateway.chat` 437 · `check.py` 110·206), 설정으로 끄거나 바꿀 자리가 없다. 최근 모델 계열은 `temperature`를 아예 받지 않거나 기본값만 받는다 — 게이트웨이가 달라질 때 고칠 자리가 「한 곳」이어야 한다는 문서 7 §7.6-B-1의 요구를 이 파라미터가 어기고 있다. 둘째(사용자 지적 2026-09-21): 원본 문서 자리 이름 `docs/`가 레포의 `docs/`(명세)와 겹쳐 사람이 헷갈리고, 이관이 그 둘을 가르려고 예외(D-160 ④)까지 두게 됐다 — 이름이 나쁘다는 증거다.
> **셋째(사내 실측 2026-09-22)**: `EMBED_MODEL`에 **로컬 모델 폴더 경로**를 넣자 임베딩이 `GatewayError HTTP 404`. 사내 임베딩 모델은 게이트웨이가 아니라 **디스크의 폴더**(bge-m3 계열)인데, 코드는 임베딩을 **게이트웨이 API 하나**로만 안다 — 그 경로 문자열을 모델 이름으로 삼아 `<LLM_GATEWAY_URL>/embeddings`에 POST했다(`embeddings.py:49` · `check.py:95`·`142`). 로컬 모델을 부르는 갈래가 없고, 설정으로 가를 자리도 없다. 그리고 `GatewayError` 문면이 `HTTP 404 — <본문>`만 찍고 **어느 URL을 쳤는지 말하지 않아** 사람이 원인을 짚을 수 없었다(M9). 사용자: 「외부 API를 쓰는 것과 방법이 구분돼야 · 설정으로」.
> **원칙**: 판정·그래프 동작 변경 0. ①③은 요청 조립을 한 자리로 모으고 손잡이 둘을 더한다. ②는 이름 하나.
> **허브 실측(2026-09-22)**: `temperature` 4곳/2파일(`gateway.py` 418·437 · `check.py` 110·206) · `check.py`의 두 탐침은 `chat()`을 거치지 않고 payload를 **따로 조립**한다(같은 기능 두 자리 — B77 ④의 규율 위반) · 설정 키에 `CHAT_TEMPERATURE` 없음 · 임베딩 요청은 `temperature`를 싣지 않는다 · `cli/register/generate.py:188` 주석이 「`temperature=0`이라 같은 입력이면 같은 코드」를 재현성의 근거로 든다.

## ① `CHAT_TEMPERATURE` — 설정 한 자리 · 비우면 키를 싣지 않는다 · 요청 조립은 `gateway` 하나 (칸 0.4)

- 설정 키 **`CHAT_TEMPERATURE`**(`llm.json`·환경변수 — 다른 키와 같은 자리 · `gateway.config()`가 읽는다). 값: 숫자면 그 값을 싣고, **없거나 `null`·빈 문자열이면 `temperature` 키를 payload에 넣지 않는다**(모델 기본값). **기본은 없음(안 싣는다)** — 근거: 받지 않는 모델에 실으면 400이고, 받는 모델은 기본값으로 돈다. 재현성이 필요한 사람이 `0`을 적는다.
- **요청 조립은 `gateway._payload(cfg, messages, *, json_schema=None, temperature=UNSET)` 한 함수**로 모은다 — `chat()`과 `check.py`의 두 탐침(②③④ 왕복 · ⑦ 이미지)이 전부 이것을 부른다. 지금처럼 탐침이 따로 조립하면 손잡이를 더해도 `llm-check`는 옛 모양을 보내 「통과했는데 인입은 400」이 난다.
- `chat(temperature=…)` 인자는 남기되 기본을 `UNSET`으로 — 인자를 주면 설정을 이긴다(호출부가 지점마다 값을 정할 자리 — 지금 그런 호출부는 0).
- `llm-check` ①설정 줄에 `temperature <값|안 싣는다>`를 한 조각 더한다 — 어느 모양을 보냈는지가 화면에 있어야 게이트웨이 400과 대조된다. **HTTP 400 본문은 이미 남긴다**(B44) — 그대로.
- `cli/register/generate.py:188`·`tests/test_p3_flow.py:209`의 「`temperature=0`이라 같다」 문면을 「`CHAT_TEMPERATURE=0`이면 같다 — 기본은 모델 몫」으로. 재현성은 설정의 결과이지 코드의 약속이 아니다(문서 7 §7.6-B에 허브가 한 줄).

**완료판정 ①**: 어서션(성질) — `CHAT_TEMPERATURE` 미설정이면 전송 payload에 `temperature` 키 0(`_post` 스텁으로 잰다 · `chat`과 `llm-check` 탐침 둘 다) · `CHAT_TEMPERATURE=0.3`이면 `0.3` · `chat(temperature=0)` 인자가 설정을 이긴다 · payload 조립 함수가 `gateway`에 하나(`grep '"messages":' core cli` → `gateway.py` 1곳) · mock 회귀 불변 · 9지점 본문 스모크(B79 ③ⓒ) 초록.

## ② 원본 자리 이름 `docs/` → `raw/` (칸 0.3)

- `paths.docs()` → `paths.raw()` · 상태 루트 폴더 `raw/` · 화면 문면(「넣을 문서가 없다 — `<상태>/raw`」) · `ingest-dir` 무인자 · 이관(`migrate`)의 옛 배치 복사 대상에서 **`docs/`를 뺀다**(옛 코드 폴더의 `docs/`는 명세다 — 원본은 사람이 넣는 것이지 이관 대상이 아니다 · D-160 ④의 포맷 가름은 이름이 갈리므로 삭제) · `DOC_EXT == reader.SUPPORTED` 어서션은 무인자 `ingest-dir`의 선별 기준으로 남긴다.
- 이미 `docs/`에 넣은 사람용: `USE_MOCK=0`에서 상태 루트에 `raw/`가 없고 `docs/`에 파서 포맷 파일이 있으면 무인자 `ingest-dir`가 **상태 거부** 「원본 자리가 `raw/`로 바뀌었다 — `mv <상태>/docs <상태>/raw`」(근거 ④). 조용히 옛 이름을 읽지 않는다.
- `doc_registry.source_path`의 상대 표기는 폴더 이름을 따라간다(`raw/…`) — 이미 `docs/…`로 기록된 항목은 `show doc`이 그대로 보이고 재인입이 덮는다(이력이지 정본이 아니다).

**완료판정 ②**: 어서션(성질) — `paths.py` 밖에 `"docs"` 문자열로 상태 경로를 조립하는 곳 0 · 옛 `docs/`만 있으면 상태 거부이고 문면에 `mv` · `raw/` 아래 문서를 무인자 `ingest-dir`가 돈다 · 이관이 옛 코드 폴더의 `docs/`를 읽지 않는다(감시 파일).

## ③ 임베딩 백엔드 `gateway | local` · `EMBED_GATEWAY_URL` · 오류 문면은 URL을 말한다 · 탐침도 한 자리 (칸 0.4)

- 설정 키 **`EMBED_BACKEND`** — `gateway`(기본) | `local`. **갈래는 `embeddings.embed()` 안 하나**다: 소비부(`matcher._narrow` · 질의)는 `list[float]`만 받고 어느 백엔드인지 모른다(§7.6-B-3 — mock 갈래와 같은 자리에서 갈린다).
  - `gateway`: 지금 그대로 + **`EMBED_GATEWAY_URL`**(선택 — 없으면 `LLM_GATEWAY_URL`). 요청은 `<EMBED_GATEWAY_URL>/embeddings`.
  - `local`: `EMBED_MODEL`은 **모델 폴더 경로**(`~`·상대 허용 — `paths` 규칙대로 절대화). `sentence_transformers.SentenceTransformer(경로)`를 **함수 안 지연 import**로 부른다(`parser/reader.py`의 `openpyxl`과 같은 결 — 선택 의존 · `USE_MOCK=1` 경로에서 import 0 · `requirements`에 선택 의존으로 등재). **프로세스당 한 번 로드**해 모듈 변수에 둔다(`paths.home()`과 같은 규율 — 매 호출 로드하면 판정 하나에 수 초). `encode(text, normalize_embeddings=True)` → `list[float]`. 패키지가 없거나 폴더가 없으면 **명시적 실패** `NotConfigured`(문면: 「`EMBED_BACKEND=local`인데 `sentence-transformers`가 없다 — `pip install sentence-transformers` · 또는 `EMBED_BACKEND=gateway`」 / 「모델 폴더 없음 <경로>」) — 조용히 게이트웨이나 겹침으로 떨어지지 않는다(`CANDIDATE_NARROW=auto`의 겹침 폴백은 **`EMBED_MODEL` 미설정**일 때만이다 — B75 ①, 설정해 놓고 못 부르는 것은 실패다).
- **`GatewayError` 문면에 URL**: `HTTP <상태> — POST <url> — <본문 앞 …>`. 404는 「그 주소에 그 경로가 없다」인데 주소가 안 보이면 사람이 설정을 못 고친다.
- `llm-check` ⑥은 **`embeddings.embed()`를 부른다**(탐침 둘 95·142의 자체 조립 삭제 — ①과 같은 병). ①설정 줄에 `embed <backend> <model|폴더> [url]` 한 조각 · ⑥ 통과 문면에 `<backend> · <n>차`.
- 판정 대장의 `path`(`embedding+judge`)는 백엔드와 무관하게 같다 — 장부는 「임베딩으로 좁혔다」만 적는다.

**완료판정 ③**: 어서션(성질) — `EMBED_BACKEND=local`에서 `embed()`가 `sentence_transformers`를 부르고 게이트웨이 `_post`는 미도달(스텁 모듈을 `sys.modules`에 심어 잰다 — 실제 패키지 없이) · 패키지 없음 → `NotConfigured`이고 문면에 `pip install` · 폴더 없음 → `NotConfigured`이고 문면에 경로 · 로드는 프로세스당 1회(스텁 생성자 호출 수) · `EMBED_GATEWAY_URL` 있으면 요청 URL이 그것을 base로, 없으면 `LLM_GATEWAY_URL`(`_post` 스텁으로 캡처) · `GatewayError` 문면에 url · `grep '/embeddings' core cli` → `embeddings.py` 1곳 · `USE_MOCK=1` 전 회귀에서 `sentence_transformers` import 0(`sys.modules` 검사) · mock 회귀 불변.
