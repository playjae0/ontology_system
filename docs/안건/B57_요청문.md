## ① provenance에 문서 이름을 싣는다 ([정정] 43) — 최우선

### 붙이는 자리는 하나다

- `_prov(rec)` → `f"{doc_id}#{loc}"`. `_Row`가 `doc_id`를 받는다(`_Row(rec, doc_id)`). 비정형은 `pipeline.py:643`에서 같은 조립.
- **`seed`·`auto:{규칙명}` 항목은 대상이 아니다** — 문서 조각에서 오는 것에만 붙는다. `_prov`가 레코드에서만 불리므로 자동으로 안전하지만 어서션으로 잠근다.

### 절대 붙이지 않는 자리 — **이 건의 1순위 리스크다**

> **계약 A의 `source_locator`는 끝까지 접두가 없다.** 파서·계약 JSON·청크 저장소의 locator는 변화 0이다([정정] 42 그대로).

`by_locator`·`loc_of`·`loc2id`(`pipeline.py:625·626·802`)는 **raw locator로 맞추는 자리**다. 여기에 접두가 섞이면 청크 대응이 통째로 깨진다. 「provenance에 붙이니 locator도 다 붙이자」로 가지 마라.

### 읽는 쪽 — 세 자리뿐이다

| Site | Now | After |
|---|---|---|
| `core/ingest.py` 회수 | `doc_locators()` 3집합 + `mine(p)` 3갈래 | `mine(p) = p.startswith(doc_id + "#")` — **`doc_locators()`는 삭제한다** |
| `cli/platform.py:261` 계기판 2 | doc_registry 훑어 `startswith(d + "-")` | `p.split("#", 1)[0]` |
| `cli/show.py:50` 화면 표기 | 문자열 그대로 | 그대로 두되 화면에서 접두가 어떻게 보이는지 보고에 한 줄 |

나머지 provenance 소비부(`build.py:323·368` · `graph.py:152` · `ops.py` 다수)는 **문자열을 뜯지 않고 넣고·세고·집합연산만** 하므로 무관하다. 손대지 마라.

### 픽스처를 내린다 — 이게 이 건의 진짜 소득이다

`tests/fixtures/parsed/CP01.json`의 `source_locator`를 **`CP01-C1` → `C1`**(접두 없음)로 내린다. 계약 A는 접두를 갖지 않는 것이 판정이고 실파서 전건이 그렇다. **지금 픽스처만 접두를 갖고 있어서 계기판 2가 mock에서만 초록이었다** — §7.5-1이 말한 「mock이 실호출 갈래를 대신하면 배선만 검증된다」의 교과서 사례다. 픽스처는 창작 자산이라 손질 대상이다(외부 LLM 실산출 스냅샷 무손질 규율의 대상이 아니다).

### 이행
마이그레이션 없음. `run.py init --fresh` 재빌드. 사내 실측 전이라 지킬 데이터가 없다.

**완료판정 ①**: ⓐ 재빌드 후 그래프의 provenance 샘플 화면 ⓑ **어서션 셋** — (i) `parsed/` 픽스처의 어느 `source_locator`도 자기 doc_id로 시작하지 않는다 (ii) 그래프의 모든 provenance 항목은 `#`를 갖거나 `seed`·`auto:`로 시작한다 (iii) **같은 locator를 가진 두 문서를 넣고 하나를 재인입하면 다른 문서의 근거가 남는다** ← 이게 이 건의 본체다 ⓒ 계기판 2가 실파서 꼴 locator에서 **None이 아닌 값**을 낸다(어서션) ⓓ `doc_locators()` 삭제 · `git diff --stat`에 순감소 확인.

## ② 공정좌표 값 부재의 처분 사다리 ([개정] B56-2)

`build_table`의 좌표 처리에 사다리 셋을 넣는다.

| Case | Disposition |
|---|---|
| `process_ref` present | 현행 그대로 |
| `process_ref` null · `process_group` present | **저해상도 부착** — `process_group`으로 해소하고 **큐를 달지 않는다** |
| both null | **`missing_field`** + payload에 `dropped_edges`·`pending_attrs`·`dropped_entities` 동봉 |

- **`STRUCTURAL`을 건드려 풀지 마라.** `process_ref`가 구조 필드인 것은 §2.5 규약 3이고, 빼면 조각이 계약대로 달고 온 필드가 `unknown_field`로 쏟아진다. **검사의 자리는 필드 검증 루프가 아니라 좌표 해소 지점**이다.
- `_land_deferred`가 `defer`가 비어도 재료 셋을 착지시킬 수 있어야 한다 — 지금은 `for item in defer:`라 0건이다.
- **새 kind 0.** 재시도 대상이 아니다(sweep이 물지 않는다).

**완료판정 ②**: ⓐ 세 경우의 화면(정상 · 저해상도 · missing_field) ⓑ 어서션 — 좌표 둘 다 null인 행을 넣으면 `missing_field` 1건이 뜨고 **payload에 드롭된 entity 표면형이 실려 있다** ⓒ `process_group`만 있는 행은 **큐 0건**이고 노드가 그룹에 붙는다.
