## ① `--resume`은 층·표본을 요구하지 않는다

**증상**: `generate <doc_type> --resume` → `IndexError: list index out of range`. 사용자가 사내에서 이걸 만났다.

**작업** — `cli/register.py::main`의 `generate` 분기:

1. `resume`이면 위치 인자는 **doc_type 하나만** 필수다. 층·표본이 오면 **무시하되 경고 한 줄**: `[생성] --resume — 층·표본 인자는 무시한다 (패키지의 값을 쓴다: layer=…, 표본 N건)`.
2. 위치 인자가 0개면 지금처럼 죽지 말고 사용법을 낸다.
3. 사용법 문안(`cli/register.py:25`)에 반영: `python cli/register.py generate <doc_type> --resume` 를 별도 줄로.
4. `--resume`인데 패키지가 없을 때의 기존 안내는 그대로 좋다.

**완료판정 ①**: ⓐ `generate <doc_type> --resume` 단독으로 돈다(실행 화면) ⓑ 층·표본을 줘도 돌고 경고가 뜬다 ⓒ 인자 0개면 사용법 ⓓ 어서션 신설 1건 이상

## ② 검수 뷰 렌더러 — 지도 필드 셋 (D-79 계약 확장)

**당신이 올린 후보가 맞다.** B48 ②-7이 노린 것의 나머지 절반이고, 데이터가 실제로 흐르기 시작한 지금이 그릴 때다.

**작업**:

1. **D-79 뷰 데이터 스키마에 3키를 먼저 추가한다** — `지도_출처`(`live`·`heuristic`·`kept`) · `지시문_판본` · `지도_없음`(사유 또는 null). 계약이 먼저이고 렌더러는 그 다음이다. `DECISIONS.md`에 스키마 변경을 적는다.
2. `kit/render_review.py` — 프레임별 지도 표에 3열 추가. **`지도_출처`는 눈에 띄게**: `heuristic`이면 경고색과 한 줄 주석(*"모델을 부르지 않았다 — 게이트웨이 설정을 확인하라"*). `지도_없음`이 있으면 그 사유를 그대로 보인다.
3. 산출자(`cli/register.py`의 뷰 데이터 조립)가 3키를 실제로 싣는지 확인 — 안 실리면 그쪽이 먼저다.

**완료판정 ②**: ⓐ 실호출 프레임과 휴리스틱 프레임이 섞인 뷰를 만들어 **HTML에서 셋이 구분돼 보이는 것**을 캡처(텍스트 발췌로 충분) ⓑ `지도_없음`이 있는 프레임의 사유가 화면에 뜬다 ⓒ 스키마 변경이 `DECISIONS.md`에 기록됐다 ⓓ 회귀 유지

## ③ ⑦ 예산 초과 문면에 감축 순서를 붙인다

**왜**: 생성 경로(`cli/prompt.py::_sent_size`)는 초과 시 **무엇을 줄이면 되는지 3단**을 낸다. ⑦은 사유만 내고 끝이라, 사용자가 화면을 봐도 다음 행동을 모른다. **관측은 행동으로 이어져야 한다.**

> **지금은 잠자는 경로다** — 사용자 판정(2026-09-04): `LLM_CONTEXT_TOKENS`를 **설정하지 않는다**(무제한). 사내 게이트웨이의 실제 한도를 모르는 상태에서 틀린 수치는 보내도 되는 요청을 막는다. 키가 없으면 `context_limit()`이 `None`이고 대조는 생략된다 — **끄는 스위치를 따로 만들지 않는다.** 이 항목은 나중에 한도를 적을 때를 위한 문면 정비이고, 동작은 지금도 나중에도 안 바뀐다.

**작업** — `core/llm.py::map_structure`의 초과 사유 문자열에 이어 붙인다:

```
⑦구조 지도 패스 — 크기 예산 초과: 약 N 토큰 > 한도 M (행 K개를 앞 20자로 줄인 뒤에도). 보내지 않았다
   이 문서는 평면으로 인입된다(구조 지도 없이 · hierarchy_unresolved 큐).
   줄이려면: ①LLM_CONTEXT_TOKENS가 게이트웨이 실제 한도와 맞는지 확인
             ②문서를 시트·슬라이드 단위로 나눠 인입
```

문면만이고 동작은 안 바꾼다. `log.explicit_fail`과 큐 사유에도 같은 문면이 간다.

**완료판정 ③**: ⓐ 예산 초과 재현 화면에 두 줄이 보인다 ⓑ 회귀 유지
