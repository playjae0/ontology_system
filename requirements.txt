# 의존 매니페스트 (문서 7 §7.6-B-6 — 선택 의존의 소재를 코드 밖에서 알 수 있게)
#
# **코어의 필수 의존은 0이다.** core/는 표준 라이브러리만 쓴다 — 폐쇄망에서 설치 없이
# 돈다(문서 1 B12). 아래는 전부 **선택 의존**이고, 없으면 그 기능만 빠진다.
# 실측은 `python doctor.py --env`가 매번 한다.
#
#   pip install -r requirements.txt          전부
#   pip install openpyxl python-pptx PyMuPDF 문서 읽기만 (실문서 인입에 필요)
#
# **PPT · PDF 인입(실호출)에 필요한 것**(B128 — 사전 점검 · `doctor --env`가 그대로 잰다):
#   ① python-pptx · PyMuPDF(아래 pip)
#   ② 캡처 길 하나 — LibreOffice(`soffice` · **Impress 포함** — libreoffice-core만이면 PPTX 변환이 안 된다)
#      또는 PowerPoint에서 PDF로 저장해 원본과 같은 폴더 · 같은 이름으로(원본보다 새것) · PDF 문서는 PyMuPDF만
#   ③ 게이트웨이의 그림 입력 — `python run.py llm-check` ⑦ 통과(실제 크기 그림 한 장)
# 셋 중 하나라도 없으면 실호출 PPT · PDF 인입은 파싱 전에 멈춘다(LLM 0). 캡처 없이 진행은 `--no-capture`(기록에 남는다).
# LibreOffice는 pip로 들어오지 않는 **외부 프로그램**이다.
#
# 런타임: Python 3.10+ (문서 7 §7.1 런타임 전제)

# ── 문서 포맷 (parser/ 전용 · 지연 import) ────────────────────────────────
# 없으면: 실 문서(.xlsx·.pptx) 읽기가 안 된다. USE_MOCK=1 전 경로는 완주한다 —
# mock/parsed/의 계약 JSON을 인입하므로 파일 읽기 단계를 타지 않는다.
openpyxl>=3.1        ; python_version >= "3.10"
python-pptx>=0.6.21  ; python_version >= "3.10"
# 없으면: `.pdf` 읽기와 **쪽 렌더**(PPT · PDF 캡처 · 그림 요약의 맥락)가 빠진다 — 실호출 PPT · PDF 인입은 사전 점검에서
# 멈춘다(`--no-capture`면 캡처 없이). XLSX는 그대로 돈다. 코드는 `import pymupdf`로 부른다(옛 판은 `fitz`).
PyMuPDF>=1.23        ; python_version >= "3.10"

# ── 직렬화 가속 (선택) ────────────────────────────────────────────────────
# 없으면: 표준 json으로 폴백한다. 계기판 7(graph MB)의 직렬화 방식 표기가 바뀔 뿐이다.
orjson>=3.9          ; python_version >= "3.10"

# ── 모델 클라이언트 ───────────────────────────────────────────────────────
# 게이트웨이는 OpenAI 호환 HTTP다. `core/llm/gateway.py`가 표준 urllib로 부르므로
# **추가 패키지 없이 동작한다** — 전용 SDK를 요구하는 게이트웨이면 그때 이 자리에
# 적는다. USE_MOCK=0의 설정은 환경변수나 `llm.json`으로 받는다
# (LLM_GATEWAY_URL·CHAT_MODEL·CHAT_TEMPERATURE 등 — `core/llm/gateway.py` 머리말 참조).

# ── 로컬 임베딩 (선택 · EMBED_BACKEND=local일 때만) ────────────────────────
# 없으면: `EMBED_BACKEND=local`이 **명시적 실패**한다(조용히 게이트웨이로 떨어지지
# 않는다 — B80 ③). `EMBED_BACKEND=gateway`(기본)는 이 패키지 없이 돈다.
# `EMBED_MODEL`은 그때 **로컬 모델 폴더 경로**다(예: bge-m3 계열).
sentence-transformers>=2.2  ; python_version >= "3.10"
