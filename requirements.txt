# 의존 매니페스트 (문서 7 §7.6-B-6 — 선택 의존의 소재를 코드 밖에서 알 수 있게)
#
# **코어의 필수 의존은 0이다.** core/는 표준 라이브러리만 쓴다 — 폐쇄망에서 설치 없이
# 돈다(문서 1 B12). 아래는 전부 **선택 의존**이고, 없으면 그 기능만 빠진다.
# 실측은 `python doctor.py --env`가 매번 한다.
#
#   pip install -r requirements.txt          전부
#   pip install openpyxl python-pptx PyMuPDF 문서 읽기만 (실문서 인입에 필요)
#
# **패키지가 아닌 의존 하나**: LibreOffice(`soffice`)는 PPTX→PDF 변환에 쓰는 **외부
# 프로그램**이고 pip로 들어오지 않는다. 없어도 완주하며 부재는 데이터로 남는다
# (`meta.slide_render=none` — 문서 7 §7.6-B-6). 있는지는 `python doctor.py --env`가 잰다.
# 주의: `soffice`가 PATH에 있어도 **impress 필터가 없으면 변환은 실패한다**(실측:
# libreoffice-core만 설치된 환경) — 그 경우도 같은 자리로 떨어진다.
#
# 런타임: Python 3.10+ (문서 7 §7.1 런타임 전제)

# ── 문서 포맷 (parser/ 전용 · 지연 import) ────────────────────────────────
# 없으면: 실 문서(.xlsx·.pptx) 읽기가 안 된다. USE_MOCK=1 전 경로는 완주한다 —
# mock/parsed/의 계약 JSON을 인입하므로 파일 읽기 단계를 타지 않는다.
openpyxl>=3.1        ; python_version >= "3.10"
python-pptx>=0.6.21  ; python_version >= "3.10"
# 없으면: `.pdf` 읽기와 **쪽 전체 렌더**(④ 이미지 요약의 맥락)가 빠진다. PPTX·XLSX는
# 그대로 돌고 그림 요약도 개별 그림만으로 돈다 — 데이터에 `slide_render=none`이 남는다.
PyMuPDF>=1.23        ; python_version >= "3.10"

# ── 직렬화 가속 (선택) ────────────────────────────────────────────────────
# 없으면: 표준 json으로 폴백한다. 계기판 7(graph MB)의 직렬화 방식 표기가 바뀔 뿐이다.
orjson>=3.9          ; python_version >= "3.10"

# 사내 게이트웨이의 실물·프로토콜이 아직 [사내 확인]이다. core/llm.py는 표준
# urllib로 HTTP를 부르므로 **추가 패키지 없이 동작한다** — 게이트웨이가 전용
# SDK를 요구하면 그때 이 자리에 적는다. USE_MOCK=0의 설정은 환경변수로 받는다
# (LLM_GATEWAY_URL 등 — core/llm.py 머리말 참조).
